# Motion Studio 0.3.1 验证记录

日期：2026-11-07，Windows x64。

配置切换快捷键由固定 F9 改为本机可配置按键，支持单键和 Ctrl／Alt／Shift 组合，旧设置默认 F9。界面提供录入、Esc 取消、恢复 F9 和目标配置禁用。只修改快捷键时保留切换前配置历史。F12 保留为独立紧急停止键。

录入期间暂停配置切换，失焦或离开页面时取消录入，租约在界面失联后到期。录入开始和结束递增版本，确保在两次后台轮询之间快速录入同一个键时，仍会重建按键基准，未松开的键不会触发切换。

验证结果：

- 原 92 项 Rust 回归测试通过，新增快速录入边界测试通过，共 93 项。
- Clippy 检查通过，无警告。
- TypeScript 和 Vite 构建通过；release 输入引擎和 NSIS 安装包构建成功。首次打包遇到一次 rustc 异常退出，重试完成。
- release 引擎进程测试 5 项通过，包括 SDL 合成输入、配置热更新、无效命令、输出保护进程空租约 EOF 和超时；真实手柄测试按原约定跳过。
- 浏览器合成 IPC 验证默认 F9、目标配置选择、Ctrl+Shift+F10、单键 F10、Ctrl+Alt+G、F12 和 Ctrl+K 拦截、Esc 取消、失焦取消、重新进入设置、恢复 F9、关闭快捷键和帮助页动态显示，页面无异常。1440×900 与 1024×680 检查通过。
- vendor 的 79 份来源文件、修补版 SDL、两份官方驱动安装包原哈希校验通过。

界面录入使用浏览器合成 IPC，组合键边沿和迁移使用纯 Rust 测试验证；没有向用户桌面发送测试按键或占用实际手柄。实际 Windows 全局按键与游戏中的切换由用户手动验收。
