# 游戏内配置提示

从 0.8.0 起，配置切换成功后可以在屏幕角落显示提示。自动光标切换、配置快捷键及运行时的手动配置切换均会通知；同一配置重复应用、普通参数保存及切换失败不会提示成功。

打开「自动切换 → 游戏内配置提示」：

- 默认启用，显示 2.5 秒，位置为右上角。
- 可以选择四个角落及显示时长，也可以关闭提示。
- 「预览配置提示」在当前屏幕显示一条示例，不启动映射、不发送输入。
- 提示跟随当前前台窗口所在的显示器，按显示器缩放比例绘制，并避开任务栏。
- 快速切换会替换旧提示并重新计时，不积压过时的配置名。

这是独立的 Windows 原生置顶浮层，鼠标穿透、不抢焦点、不出现在任务栏。背景与文字采用 Studio 暗色提示样式，支持中文名称，长名称使用省略号；结束前短暂淡出。渲染与配置通知位于桌面进程的独立线程，不参与引擎的逐采样输入与输出发送。

窗口化和无边框全屏通常可以显示。真正独占全屏、特定图形呈现模式或游戏自身的覆盖限制可能使系统浮层不可见，不能承诺所有“全屏”模式都有效；可以尝试游戏中的无边框全屏选项。本功能没有游戏内注入、图形 API hook 或反作弊绕过功能。Windows 全屏优化、无边框和独占全屏的差异见 [Microsoft 全屏优化说明](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/)，鼠标穿透与分层窗口行为见 [Microsoft Window Features](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

本机设置字段为 `overlay_enabled`、`overlay_duration_ms`（1000–8000）和 `overlay_position`。不会混入分享的游戏 TOML 配置。旧版本本机设置缺少这些字段时使用默认值。

自动化只验证模拟命令、设置交互、消息替换、布局计算与窗口样式契约，不会在用户桌面自动弹出原生浮层或启动游戏。用户可点击预览并在游戏中手动检查可见性、焦点和鼠标穿透。
