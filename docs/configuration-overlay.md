# 游戏内配置提示

配置切换成功后，可以在屏幕右下角显示一行配置名称。自动光标切换、配置快捷键及运行时的手动配置切换均会通知。同一配置重复应用、普通参数保存及切换失败不会提示成功。

打开「自动切换 → 游戏内配置提示」：

- 默认启用，显示 2.5 秒。可以调整显示时长或关闭提示。
- 「预览配置提示」在当前屏幕显示一条示例，不启动映射、不发送输入。
- 提示跟随当前前台窗口所在的显示器，按显示器缩放比例绘制，并避开任务栏。
- 快速切换会替换旧提示并重新计时，不积压过时的配置名。

这是独立的 Windows 原生置顶浮层，鼠标穿透、不抢焦点、不出现在任务栏。背景与文字采用 Studio 暗色提示样式，支持中文名称，长名称使用省略号；结束前短暂淡出。渲染与配置通知位于桌面进程的独立线程，不参与引擎的逐采样输入与输出发送。

窗口化和无边框全屏通常可以显示。真正独占全屏、特定图形呈现模式或游戏自身的覆盖限制可能使系统浮层不可见，不能承诺所有“全屏”模式都有效；可以尝试游戏中的无边框全屏选项。本功能没有游戏内注入、图形 API hook 或反作弊绕过功能。Windows 全屏优化、无边框和独占全屏的差异见 [Microsoft 全屏优化说明](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/)，鼠标穿透与分层窗口行为见 [Microsoft Window Features](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

开关和显示时长保存在本机的 `overlay_enabled` 与 `overlay_duration_ms`（1000–8000）字段中。新旧配置统一在右下角显示提示。

自动化只验证模拟命令、设置交互、消息替换、布局计算与窗口样式契约，不会在用户桌面自动弹出原生浮层或启动游戏。用户可点击预览并在游戏中手动检查可见性、焦点和鼠标穿透。

## 录屏用三维悬浮手柄

在「设备与输入」或「设置与组件」中打开「三维悬浮手柄 → 显示悬浮手柄」。它复用实时输入页面的三维模型和动画，显示按键、摇杆、扳机及支持的触摸板动作。可选择显示器、屏幕四角、大小、不透明度，以及是否跟随手柄姿态；跟随模式会以连接后的首次有效姿态作为当前显示的基准。没有可用三维图形时回退到二维显示。

悬浮窗使用透明背景、始终置顶和鼠标穿透，不抢焦点，主窗口最小化后继续显示。先开始映射或观察输入，悬浮窗才有实时动作；打开悬浮窗本身不会启动输入会话。停止、断线、引擎故障或状态过期后，按键和摇杆恢复中立并显示等待状态。退出 Motion Studio 会关闭悬浮窗。设置保存在本机 `controller_overlay` 对象中，旧设置默认关闭此功能。

录屏可使用显示器捕获，将游戏与这个独立窗口一起录入。OBS 的 [显示器捕获](https://obsproject.com/kb/display-capture-sources) 录制整个显示器，而 [游戏捕获](https://obsproject.com/kb/game-capture-source) 直接读取游戏画面；仅使用游戏捕获不应假定会包含这个桌面窗口。游戏建议使用无边框窗口模式，独占全屏的可见性仍需实机确认。
