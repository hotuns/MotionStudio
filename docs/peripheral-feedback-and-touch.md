# 游戏反馈、触摸板与体感录入

Motion Studio 可将虚拟手柄收到的游戏震动和灯光回传给实体手柄，也能把触摸板输入转换为鼠标手势。触摸接触可以绑定到普通动作、体感启停、暂停输入与按住配置层。

## 游戏震动与灯光

在「游戏配置 → 游戏震动与灯光」设置。震动和灯光分别启停，震动强度为 0–2×，最终幅度限制在原生 0–1 范围。配置可以随 TOML 分享，也能被配置层覆盖。虚拟手柄选择键鼠模式时，没有游戏手柄反馈源；Xbox／DualShock 4 才有。

游戏先向虚拟手柄发送反馈，由原生 `VirtualXInput`、`VirtualDS4` 或 `HidMaestroDevice::poll_outputs` 接收，再通过原生 SDL `DeviceBackend::send` 交给当前选中的同一个实体手柄句柄。没有额外打开一份手柄，也没有调用聚合输入 `poll()`。Xbox 主要提供两个震动马达，DS4 还提供灯光；实体接口是否支持这些能力由 SDL 报告，界面显示为支持或未报告支持。

每 8 ms 检查最新反馈。持续震动时，每 250 ms 续期 SDL 的 1 秒请求。灯光命令会合并并限制发送频率，最后一次颜色变化也会提交。

录入、停止、断线、校准或配置切换会释放已接管的震动，并取消待发送的颜色。恢复时丢弃旧的反馈基线，等游戏的新命令；即使新命令的强度与旧命令相同也可恢复。命令序号与实际读取的反馈值保持同一快照。仅观察输入不会发送反馈清理指令，也不会接管设备震动。停止灯光回传后保持设备最后颜色，不假装知道设备原来的颜色。

界面上的反馈电平表示软件接收／提交的状态，不是马达已经动作的硬件确认。未报告对应能力的接口可能不接受该种反馈，尤其是同一手柄分别提供体感和普通 XInput 接口的情况。

## 原生触摸板鼠标

在「游戏配置 → 触控」开启「启用触摸板鼠标」，分别设置指针速度、滚动速度和自然滚动。点击「查看触控绑定」可筛选动作列表中的相关绑定。默认关闭，旧配置不会因为升级而突然移动鼠标。

| 输入 | 原生行为 |
|---|---|
| 单指滑动 | 移动指针 |
| 双指滑动 | 垂直／水平滚动，保留小数滚动余量 |
| 单指轻点 | 左键短脉冲，自动释放 |
| 双指轻点 | 右键短脉冲，自动释放 |
| 按下触摸板并移动 | 按住拖动；按下时决定左右键，期间换手指不会换键 |
| 双触摸板设备 | 左板滚动／右键，右板移动／左键，双板同时按下为中键 |

手势处理保留按下、移动和抬起的原始顺序与时间戳。单板可识别两根手指，双板各自记录触点。

开启、修改触摸设置或重连时，如果手指已经接触，会先等全部抬起。录入时只释放输出，保留设备，恢复也等待触点与按键松开；不会把抬手误判成一次新轻点。长时间断流、无效坐标和关闭路由都会清除待处理的点击与滚动。已有按键映射与手势输出按键状态合并，避免一条路径释放另一条路径仍按住的按键。

「实时触摸预览」显示原始触点，支持最多两个原生触摸字段。动作列表里「触摸板按下」仍指物理按键，保持旧配置含义；开启触摸板鼠标后，它与动作列表映射可以同时执行。

## 用接触开启体感或配置层

普通输入选择增加「触摸接触 1／2」，配置标识分别为 `touch1`、`touch2`，可以单独使用，也可与肩键等组成最多四个输入的组合。

- 在「游戏配置 → 体感 → 体感行为」中，开启与暂停的选择器都能搜索按键或浏览「触摸板」分组。开启方式选「按住开启」或「按一下切换开关」后会显示开启按键。选「触摸接触 1」可以用手指接触。选「触摸板按下」需要压下板上的物理开关。双触摸板设备分别显示两个按下选项。
- 两个选择器旁都可以「监听手柄」。录入期间暂停游戏输出并保持原手柄连接。按下或接触一个输入后，全部松开才写入当前配置草稿。触摸板按下优先于同一块板的接触。开启与暂停各使用一个不同的输入。录入可按 Esc、点击取消或离开当前页面。录入结束后按「保存配置」或「应用修改」。
- 按住层输入选择「触摸接触 1 + 左肩键」：接触并按肩键时使用这一层的灵敏度。
- 动作输入选择触摸接触：使用现有按住、短按、长按、双击等触发器。

单触摸板的 1／2 是两根手指。双触摸板的 1／2 分别是左右板的接触。关闭触摸板鼠标时也能用接触触发体感、动作和配置切换。参见[快捷键切换](controller-shortcuts.md)。

示例：[触摸板鼠标](../examples/touchpad-mouse.toml)、[触摸开启体感与肩键层](../examples/touch-to-aim.toml)。专用 HID provider、触摸分区编辑、原生 DS4 传感器透传及 DualSense 音频等不在本版声明的覆盖范围内，多传感器融合保持排除。

## 无真机验证

自动测试用合成触点验证手势处理，用模拟接收端核对新命令、同电平新命令、暂停、释放与续期。SDL 测试用仅存在于进程内的虚拟输入验证触点结构、事件顺序和光标位移。

## 四方向滑动映射

在「游戏配置 → 动作映射 → 添加动作」的左侧手柄输入区切换到「触摸板」分类，选择上滑、下滑、左滑或右滑，再选择输出按键。触控页的「查看触控绑定」也包含这些动作。无需开启触摸板鼠标；若同时开启，两种输出会同时生效。

复用 FlexInput Touch Zones：从落指位置沿主要方向移动超过触摸板约 18% 时识别一次，输出约 120 ms 的脉冲，抬手后可重新识别。两根手指或两块板的同方向信号合并。推荐默认的「按住」触发，表示在脉冲期间按住输出；默认 250 ms 长按不会被 120 ms 手势脉冲触发。当前通过输入选择器手动选方向，监听手柄仍识别接触或物理按下。

## 统一手柄选项目录

Studio 的 `controller-catalog.ts` 统一定义按键、十字键、扳机键、摇杆、陀螺仪和触摸板分类。动作弹窗的分类按钮、完整输入选择器、配置层、体感控制按键、手柄快捷键和虚拟手柄输出共用分类与名称，并按调用入口允许的信号筛选。

摇杆按下、方向与内外圈统一放在摇杆分类；整根摇杆仅在虚拟手柄映射中提供，并独占输入，不能加入按键组合。陀螺仪的姿态、角速度和加速度仍通过体感动作配置量程与阈值，不作为普通数字按键加入组合。虚拟手柄只显示该输出目标支持的控件。体感动作的原生输出 pin 名称通过目录转换，保存的配置格式不变。

键盘沿用现有按键目录和组合逻辑，动作弹窗增加全键位搜索入口。F12 继续保留为紧急停止，不进入可映射目录。
