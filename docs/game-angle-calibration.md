# 游戏内转角校准

在「游戏配置 → 体感 → 游戏内转角校准」测量体感输出与游戏视角角度之间的基础换算比例。陀螺仪零偏校准位于「设备与输入」。

推荐使用「测量水平 360°」：

1. 保存并应用游戏配置，启用映射输出。进入游戏训练场等方便观察的场景，对准一个清楚的参照物。
2. 点击「测量水平 360°」，使用体感朝同一方向转动游戏镜头。
3. 游戏镜头转完一整圈，重新对准参照物后结束测量。游戏视角需要转 360°，手柄本身不需要转 360°。
4. 点击「将测量结果填入当前配置」，再保存并应用配置。

显示的累计角度是手柄净转角。反向转动会抵消累计角度；软件不能读取游戏镜头角度，需要用户手动确认是否完成整圈。测量过程中暂停、丢失采样、重置姿态等情况会使结果失效。

鼠标输出的换算为：`新 counts_per_degree = 原 counts_per_degree × |手柄净转角| / 360`。例如原值 12，游戏转一圈时手柄实际转了 90°，校准后基础值为 3。正常映射会继续使用配置中的体感倍率；快推转身和指定角度转身也依赖准确的基础转角比例。

「测量垂直 180°」假定游戏从最低看到最高恰好有 180°。许多游戏限制俯仰范围，因此应优先用水平校准；不能把任意游戏的上下限直接视为 180°。

虚拟右摇杆输出校准的是满杆转速尺度，仍受游戏的死区、加速曲线和最高转速影响。请缓慢、平稳地测量；超过满杆速度时界面会要求重测。换游戏、修改游戏内灵敏度或瞄准倍率后，需要重新核验对应场景的校准。
