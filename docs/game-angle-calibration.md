# 游戏内转角校准

在「游戏配置 → 体感 → 游戏内转角校准」测量体感输出与游戏视角角度之间的基础换算比例。陀螺仪零偏校准位于「设备与输入」。

推荐使用「测量水平 360°」：

1. 保存并应用基础层配置，启用映射，点击「打开校准悬浮窗」。进入游戏训练场等方便观察的场景，对准一个清楚的参照物。
2. 在悬浮窗点击「测量水平 360°」。可以沿当前配置中 Flick Stick 所选摇杆的外圈绕动，再用体感微调。也可以全程用体感转动镜头。
3. 游戏镜头回到同一参照物后松开摇杆并等镜头停稳，点击「结束测量」。需要转满 360° 的是游戏镜头，悬浮窗显示的是手柄体感和摇杆扫动合计的净转角。
4. 在悬浮窗点击「保存并应用校准」。如需重测，点击「重新测量」。关闭悬浮窗会取消尚未结束的测量。

悬浮窗置顶，鼠标能移到面板时可直接点击，点击不会激活 Studio。请使用窗口或无边框全屏模式。游戏锁定光标时，可以用悬浮窗显示的按键在游戏前台操作。

- `Ctrl+Shift+F8` 开始水平 360° 测量，测量中再次按下会结束。已有结果时可用它重测。
- `Ctrl+Shift+F9` 保存并应用有效结果。保存后再次按下会关闭悬浮窗。

按键随校准窗口注册和释放。组合键被占用时，对应提示会隐藏，可以用游戏菜单调出光标后点击控件。引擎的实时转角由桌面端直接推送给悬浮窗，读数与主窗口焦点无关。悬浮窗打开期间暂停配置自动切换，测量和应用都绑定到打开时的映射。映射停止、重连或配置更改后，重新打开悬浮窗开始校准。

反向转动会抵消累计角度。以游戏内的参照物判断是否完成整圈。测量时所选摇杆的普通映射、Flick 转身和连续摇杆鼠标会暂停，防止两路输出一起移动镜头。测量过程中暂停、丢失采样或重置姿态会使结果失效。

鼠标输出的换算为：`新 counts_per_degree = 原 counts_per_degree × |手柄净转角| / 360`。例如原值 12，游戏转一圈时手柄实际转了 90°，校准后基础值为 3。正常映射会继续使用配置中的体感倍率；快推转身和指定角度转身也依赖准确的基础转角比例。

「测量垂直 180°」假定游戏从最低看到最高恰好有 180°。许多游戏限制俯仰范围，因此应优先用水平校准；不能把任意游戏的上下限直接视为 180°。

虚拟右摇杆输出校准的是满杆转速尺度，仍受游戏的死区、加速曲线和最高转速影响。请缓慢、平稳地测量；超过满杆速度时界面会要求重测。换游戏、修改游戏内灵敏度或瞄准倍率后，需要重新核验对应场景的校准。
