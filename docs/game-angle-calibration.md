# 游戏内转角校准

在「游戏配置 → 体感／摇杆 → 输出与转角校准」设置游戏视角角度的基础换算比例。两页使用同一组输出和校准值，Flick 和配套摇杆瞄准也使用这组值。「游戏满杆角速度」记录游戏实际满杆转速，不是提高游戏速度的倍率。陀螺仪零偏校准位于「设备与输入」。

## 在游戏前台用手柄校准

1. 保存并应用基础层配置，启用映射，打开校准悬浮窗。在游戏训练场对准一个参照物。窗口或无边框全屏下可以同时看到悬浮窗和游戏画面。
2. 按右侧面键组的**下键**（Xbox A、PlayStation ×、Switch B）试转 360°。观察是否刚好转过一圈。没转够按十字键左，转过头按十字键右，每次微调 1%。重新对准参照物，按面键下再试一次。
3. 满意后按**面键上**保存并应用，再按一次关闭。鼠标也可以直接点面板上的按钮。

需要手动测量时，按**面键左**进入「更多校准方式」。按面键下开始水平测量，或按面键左开始垂直测量。让镜头转到终点，松开摇杆，等镜头停稳，再按面键下结束。测量值会填入校准草稿，按面键上保存。面键右用于取消当前测量、返回或关闭，具体操作见悬浮窗按钮。

校准按键由当前映射的实体手柄提供。悬浮窗打开期间，这些按键由 Studio 用于校准，原来绑定在这些键上的游戏动作暂时停用。映射停止、手柄重连或切换配置后，请重新打开悬浮窗。

反向转动会抵消累计角度。以游戏内的参照物判断是否完成整圈。测量时所选摇杆的普通映射、Flick 转身和连续摇杆鼠标会暂停，防止两路输出一起移动镜头。测量过程中暂停、丢失采样或重置姿态会使结果失效。

鼠标输出的换算为：`新 counts_per_degree = 原 counts_per_degree × |手柄净转角| / 360`。例如原值 12，游戏转一圈时手柄实际转了 90°，校准后基础值为 3。正常映射会继续使用配置中的体感倍率；快推转身和指定角度转身也依赖准确的基础转角比例。

「测量垂直 180°」假定游戏从最低看到最高恰好有 180°。许多游戏限制俯仰范围，因此应优先用水平校准；不能把任意游戏的上下限直接视为 180°。

虚拟右摇杆输出校准的是满杆转速尺度，仍受游戏的死区、加速曲线和最高转速影响。请缓慢、平稳地测量；超过满杆速度时界面会要求重测。换游戏、修改游戏内灵敏度或瞄准倍率后，需要重新核验对应场景的校准。

## 测量游戏的摇杆响应曲线

要补偿游戏的「标准」或「动态」曲线，请保持平时使用的游戏灵敏度。Studio 会将虚拟右杆固定在指定位置。每档都可以选择测几圈，只需在第一圈开始和最后一圈结束时按键。满杆转得快时可以多测几圈，让起止按键的时间误差在总用时里占得更小。

1. 选用虚拟手柄输出，保存并应用基础层配置，启用映射。打开「游戏配置 → 摇杆 → 虚拟右摇杆响应 → 在游戏中测量曲线」。体感关闭时也能使用。在游戏训练场里选好曲线和灵敏度，找一个远离瞄准辅助目标的固定参照物。若要测开镜曲线，可先在游戏里用切换式开镜保持瞄准。推杆期间 Studio 会释放扳机等其他输出。
2. 首档是 100%。推杆前按**面键左**切换本档圈数，可选 1、3、5、10、20 圈。例如高灵敏度下选 10 圈，松开实体右杆，按**面键下**开始推杆。等转速稳定，在准星经过参照物时按面键下标记起点，算作第 0 圈。此后每次回到参照物数一圈，第 10 次回来时再按面键下，这一档随即回中。
3. 按同样的方法测 25%、50%、75%。各档可以独立选择圈数，低速档测 1 圈即可。若镜头确实静止，可以在已经开始推杆、尚未标记起点时按**面键左**记为 0% 转速。面键右可以停止本档输出，十字键左右可切换档位重测。等待起点和标记起点后的整段计时各有 60 秒限时，圈数要选在限时内能完成的档位。
4. 四个档位完成后就可以保存。如果游戏在轻推或接近满杆时转速变化明显，可以用十字键选 10% 或 90% 加测，实测点会一并写入曲线。
5. 核对悬浮窗显示的「推杆量 → 游戏转速」，按**面键上**保存为当前配置的分段曲线。Studio 先用每档的总用时除以圈数，再用满杆的平均每圈用时除以该档的平均每圈用时。例如满杆 10 圈用 5 秒，半杆 3 圈用 3.75 秒，半杆转速就是满杆的 `0.5 ÷ 1.25 = 40%`，对应点是 `(50%, 40%)`。保存会保留「游戏满杆角速度」和「矫正实体摇杆输出」原有设置。

如果满杆快到现场数不清圈数，可以在保持原灵敏度时录下各档稳定转动的画面。慢放选出准星经过同一参照物的起止帧，数清两帧之间转了多少整圈，用录像原始时间戳之差除以圈数。按上面的公式算出各档相对转速，就可以直接填入「游戏摇杆响应 → 分段曲线」。

验证实体右杆时，将它映射到虚拟右杆并开启「矫正实体摇杆输出」。如果满杆一圈 2 秒，补偿后**实体有效推杆量**在 50% 时应接近 4 秒一圈。也可以试试没有参与拟合的 60%，预期约 3.33 秒。慢速区域如果仍有偏差，可以在分段曲线中继续添加或移动控制点。

「标准」和「动态」各测一份。如果固定推杆量时，第一圈和后续各圈耗时有明显差异，游戏可能还采用了随时间变化的加速。静态曲线能拟合稳定后的转速，起步过程仍可能有差异。
