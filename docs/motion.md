# 体感调校

「游戏配置 → 体感」包含行为、灵敏度、防抖、高级转向与游戏内转角校准。体感动作和定角转身在「动作映射」编辑，Flick Stick 位于「摇杆」。传感器校准位于「设备与输入」。

## 输入与单位

输入层使用 FlexInput SDL3 设备模块，逐条读取陀螺仪和加速度计事件。SDL 陀螺仪使用 rad/s，加速度计使用包含重力的 m/s²。两类传感器时间戳分别保留，不用加速度计事件重复积分陀螺仪。算法层统一换算到 FlexInput 的角速度和加速度坐标。加速度事件超过 50 ms 未更新时，不再驱动依赖重力的功能。没有加速度计的设备可以继续使用本地角速度瞄准。

SDL 轴为右、上、后。对应 FlexInput 陀螺仪 forward/right/down = (-SDL Z, SDL X, -SDL Y)，加速度 forward/left/up = (-SDL Z, -SDL X, SDL Y)。标准重力为 9.80665 m/s²。当前使用未经修改的官方 SDL；Apex 6 Pro 固件修复后已撤掉 Flydigi device 150 的自定义陀螺仪换轴，加速度和厂商轴向均不额外修正。来源：[SDL_SensorType](https://wiki.libsdl.org/SDL3/SDL_SensorType)、[SDL_GamepadSensorEvent](https://wiki.libsdl.org/SDL3/SDL_GamepadSensorEvent)。真实设备握持和轴向需由使用者验证。

## 行为与坐标

- 本地俯仰与偏航：原有鼠标／右摇杆瞄准方式。支持将横滚的一部分混入水平转向。
- 本地俯仰与横滚：用横滚控制水平转向。
- 玩家／世界坐标：基于重力估计投影角速度。固定版本上游使用不同的重力平滑时间，世界坐标参考变化较慢。
- 握持补偿：按习惯的俯仰、偏航、横滚角度重测控制方向。
- 姿态控制：累积转角控制虚拟摇杆，手柄停止转动后保持偏转。设置满杆角度、单水平轴与归零过渡。上游自动回中只覆盖本地坐标的水平轴；垂直轴需手动归零，玩家／世界坐标无法从重力恢复水平朝向。
- 体感旋转摇杆：手指决定方向，手腕细调角度，保留推力；支持方向稳定、相对回归和体感接管，外圈交还拇指。与 Flick 使用同一摇杆时会拒绝配置。
- 姿态归零记录当前朝向；设置正前方只重置水平朝向，保留俯仰与横滚。姿态来自软件积分，SDL 输入接口不提供设备融合四元数。重力只能修正倾斜漂移。

## 响应与稳定

可选线性、自然、幂函数、二次、S、跳变和多点自定义加速曲线。自定义曲线横轴为 °/s，纵轴为倍率。控制点严格按横坐标递增，最多 32 个。

平滑可选 EMA、速度衰减平滑或 One Euro。保留手动静止抑制，增加实测噪声底抑制、低速截止及恢复、角度吸附和减速刹车。One Euro 的速度系数提高后，快速动作更快退出强平滑。

Trackball 用最近 125 ms 的时间加权角速度开始惯性运动，按住指定方向按键保持并按配置衰减，松开恢复手腕输入。暂停、无效采样和采样超时清理惯性状态。

## 高级转向

边缘转向通过姿态角度确定出界。可选择随角度提速、保留出界速度或两者结合。过渡宽度控制接管强度，保留手腕份额决定边缘处的直接操作权。用姿态归零键确定中立位，回拉可制动。

Flick Stick 快推选择朝向，沿摇杆外圈转动镜头。可设置正前方死角、完成时间、方向稳定、快速推杆时间与慢推锁定。Flick 和配套摇杆瞄准共用「体感输出」，一起走鼠标或虚拟右摇杆，并使用该模式的游戏内转角校准值。默认屏蔽对应实体摇杆的自动映射，也可改为外圈屏蔽或保留。Flick 和定角转身的虚拟摇杆输出受满杆转速限制，来不及完成的转角后续继续输出。按住暂停会取消尚未完成的转角。

在「游戏配置 → 摇杆 → Flick Stick 与摇杆瞄准」启用 Flick 后，可调整 0–100% 的「转角缓出强度」，默认 50%。0% 匀速释放，50% 使用 JSM 的二次缓出，0–50% 之间混合两种曲线。50–100% 继续增强前段释放，100% 使用三次缓出，让更多转角在起步阶段完成。图中横轴为时间进度，纵轴为已完成的转角比例，虚线是匀速参考。完成时间为 0 时立即输出全部转角。虚拟摇杆受游戏最大转速限制时，实际完成时间可能更长。

强度以 `gyro.motion.flick.release_ease` 保存，范围为 0–1，支持按住配置层覆盖。已有的显式强度值按当前比例解释，50% 对应 JSM 缓出。新配置以及缺少此字段的旧 Studio 文件采用 0.5。新导入的 JSM Flick 配置也采用 0.5，以保留 JSM 的释放曲线。

## 动作

绑定对象包括有符号或单方向的角速度、倾斜角和去重力后的线性加速度。满量程分别使用 °/s、° 和 g；阈值是映射曲线后的满量程比例。支持保持、切换和连发，输出键盘、鼠标按钮或虚拟手柄轴、扳机和按钮。双向输入映射轴时保留符号，映射键鼠按钮时比较绝对量。体感动作不依赖瞄准开启键，体感总开关和按住暂停控制它们。

定角转身可独立绑定按键，设置正负角度、完成时间和输出方式。重连或热更新时已有的按键快照不会触发转身。Flick 摇杆若在快照中已推向外圈，会等待先回到中心，再接受下一次转向。

## 校准

静止校准：等待 2 秒后采样，5 秒完成；测量陀螺仪零偏、陀螺仪噪声和加速度噪声。移动或样本不足时拒绝保存。

加速度六面校准：将 SDL 的 X、Y、Z 正负方向分别朝上并放稳，每个轴记录两面后计算偏移及比例。错方向和移动时拒绝记录。设备校准提供传感器轴反转与安装方向旋转，数据按设备路径保存在本机，分享配置不携带它们。

游戏转角测量：保存配置、启用输出并进入游戏，按参照点完成水平 360° 或垂直 180°，结束测量后将结果填入配置，再保存应用。程序无法读取游戏镜头，需要用户手动对齐。测量使用基础输出比例，忽略灵敏度倍率、加速和边缘转向；测量期间屏蔽虚拟右摇杆原始输入、Flick、体感动作和定角转身。鼠标计数新值 = 旧值 × 实测手柄角 / 游戏转角；满杆转速新值 = 旧值 × 游戏转角 / 实测手柄角。摇杆饱和、采样中断或无效时间戳的测量不能用于填入结果。

## 来源与范围

3DOF、边缘转向、Flick、摇杆方向旋转、IMU 量估计、曲线采样复用固定版本 FlexInput 的纯 Rust 实现。motion_curves.rs 转出上游 jsm/cc.rs 的曲线接口，许可见 licenses/FlexInput-MIT.txt。Trackball 适配为时间加权历史，定角转身借鉴上游 RWS 的剩余角度结算。

输入、SendInput、ViGEmBus 输出、配置和运行态由 Motion Studio 管理。多传感器融合不在本次范围。虚拟 DS4 仍为标准输入报告，不转发实体 IMU；这与在应用内用体感控制鼠标／摇杆是不同输出能力。
