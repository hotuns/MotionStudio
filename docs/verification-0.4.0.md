# Motion Studio 0.4.0 验证记录

日期：2026-11-07，Windows x64。

游戏配置与按键映射合并为「游戏配置」，包含「动作映射」与「摇杆设置」。动作支持最多四个手柄输入，以及最多四个键鼠输出成员；支持 Ctrl／Alt／Shift、鼠标五键、四向滚轮与可选的连续滚动间隔。旧单键配置保持可读取。

验证结果：

- 103 项 Rust 测试通过，包含组合 AND 与严格超集优先、模拟轴阈值、共享修饰键、单次和连续滚轮、停止／断开／快照不重放、输出失败清理、侧键和滚轮 Windows INPUT 格式，以及短促手柄组合遥测。
- Rust 格式检查和 Clippy 通过，无警告。
- TypeScript、Vite、release 输入引擎、桌面应用和 NSIS 安装包构建通过。最终前端包含 Shift+数字键的录入修正。
- release 输入引擎的 5 项进程协议测试通过，覆盖 SDL 合成传感器事件、有效／无效热更新、配置切换、错误 IPC、体感命令拒绝和空租约保护进程失联。按原约定跳过真实手柄测试。
- 使用隔离 Chrome、合成 Tauri IPC 验证 16 组流程：合并入口与摇杆分类、手动组合与重复项限制、Ctrl+Shift+K 录入、F12 拒绝和 Esc 取消、单独修饰键、四向滚轮、Ctrl+滚轮+侧键与间隔、侧键 1、Alt+侧键 2、取消／失焦、手柄组合松开后提交、快速手柄组合、表格快捷录入、Shift+数字键、组合标签搜索、浅深色及 1024×680 布局。无页面异常，截图保存在本机 .test-data/ui-check/。
- vendor 的 79 份来源文件、修补版 SDL 和两份官方驱动安装包原哈希校验通过。

纯 Rust 使用模拟输出接收端，界面使用浏览器合成输入与 IPC。鼠标侧键通过隔离浏览器的 CDP 输入验证，未向用户桌面发送按键、滚轮或鼠标点击。真实设备、游戏中的组合识别、侧键语义和滚轮手感由用户手动验收。
