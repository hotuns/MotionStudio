# Motion Studio 0.9.0 验证记录

日期：2026-11-08，Windows x64。

## 本轮改动

- 光标自动切换原有 250 ms 固定确认时间改为可配置整数 0–5000 ms，默认兼容旧值。保留约 50 ms 检查周期，设置改变后重建基准，并在操作锁后重新检查录入状态和目标。
- 「编辑层」移到顶栏当前配置右侧，各页面共用；管理窗口保留新增、删除、组合启用、优先级、恢复继承和运行层显示。选择编辑层不启用运行层或重开映射。
- 映射窗口参考旧 JSM Studio 的快速按键选择和完整编辑方式，改为双栏录入、手柄按钮、六种触发方式、键盘布局、鼠标／滚轮分类、可删除的组合标签及完整设置。保留运行中输出暂停录入、四成员上限和手柄界面操作。
- 新动作输出必须明确选择，修饰键单独选择不会附加默认空格。修复嵌套区域的 LB／RB 导航，补齐 optgroup 标签的即时翻译。

## 发布验证

- 静态 CRT 引擎、桌面应用和 Windows x64 NSIS 安装器构建成功，产品版本 0.9.0。
- 桌面程序内固定的最终引擎 SHA-256 与资源一致，四个 HIDMaestro 内嵌载荷和既有运行功能标记核验通过。
- 引擎 PE 仅延迟导入同一份 SDL3.dll，桌面程序无 SDL 导入；142 个 vendor 文件及固定运行资源完整性校验通过。
- 安装包与便携包由发布脚本核对产品版本、资源哈希、输入 provider 元数据、说明文档、许可证、示例及 ZIP 必需文件。校验值写入 `artifacts/checksums.json`；预览图为模拟数据的无头界面截图。
- HIDMaestro 驱动保持 2.0.0.2201，SDL 与固定 FlexInput vendor 不变；升级应用即可，无需重装驱动。

光标实际响应、真实手柄操作和游戏表现由用户真机验收；0 ms 只取消额外确认等待，不代表端到端零延迟。
