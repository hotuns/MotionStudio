# Motion Studio 0.5.0 验证记录

日期：2026-11-07，Windows x64。

新增离线 JSM 转换、逐行预览与新配置创建，以及独立 SDL 手柄界面观察模式、焦点导航、控件编辑、屏幕键盘和应用内文件选择器。协议版本升级为 4。

已完成验证：

- 122 项 Rust 测试通过：原 103 项回归，加 15 项 JSM 转换、2 项导航意图、2 项主进程导航状态测试。
- JSM 覆盖普通键鼠、侧键滚轮、显式组合、轻按／长按区别、设置覆盖和重置、校准与单位、灵敏度和轴向、体感开关／惯性、曲线与 One Euro、完整与部分虚拟布局、无效数值、关键体感项关闭和外部命令不执行。
- 导航覆盖快照不伪造按下、短促按下保留、有限队列、摇杆迟滞、进入界面前释放输出、空白观察配置不写文件监视、断开清空旧导航。
- Rust 格式检查、Clippy、TypeScript 与 Vite 构建通过。
- 最终 release 引擎、桌面程序与 NSIS 安装包构建通过；最终前端包含焦点恢复与键鼠录入单次提交修正。
- release 引擎 6 项进程测试通过，覆盖 SDL 合成事件、有效／无效热更新、配置切换、错误协议、体感命令拒绝、保护进程失联，以及无配置的 Navigate／扫描／停止。真实手柄测试按原约定跳过。
- 隔离 Chrome 中 16 组 JSM／手柄流程通过。JSM 使用本次真实 Rust 转换器作为测试服务：预览与名称、UTF-16／中文 ANSI、不可迁移报告、TOML 文件选择、区域导航、下拉框、屏幕键盘、数值调整与撤销、实体录入、失焦、继续游戏与 View+Menu、紧凑深色、空配置库自动观察与首份配置、重连基准、方向重复与确认单次。
- 上一版组合键／滚轮／侧键的 16 组界面流程全部通过，共 32 组，无页面异常。检查了浅深色、1440×900 和 1024×680。
- 补充了后台界面快照落后的场景：恢复焦点前重新获取引擎基准，并丢弃旧的在途状态请求，防止后台确认键被重放。重启后的输入序号也重新建立基准。
- 键鼠录入采用单次提交，覆盖滚轮与修饰键松开在同一浏览器任务内到达的情况，防止后一次松开覆盖已录入的 Ctrl+滚轮。
- vendor 的 79 份来源文件、修补版 SDL 和两份官方驱动安装包原哈希验证通过。

浏览器的设备状态和文件选择使用合成 IPC，输出接收端使用模拟实现。未占用用户实际手柄、向桌面发送测试输入、运行游戏、安装新驱动或改变隐藏规则。真实手柄导航、游戏输出与手感仍由用户手动验收。

针对三角洲可能不接受 SendInput 的反馈，核查了 Microsoft 文档、FlexInput 固定提交、HIDMaestro、FakerInput 官方源码与 DS4Windows 文档，并记录输出候选路径。0.5.0 未实现或安装 HIDMaestro／FakerInput／VHF／Interception，未宣称解决三角洲反作弊兼容性。
