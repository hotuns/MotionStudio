# Motion Studio 0.6.1 验证记录

日期：2026-11-07，Windows x64。

用户反馈 HIDMaestro 可启用，但体感／摇杆鼠标跳动、不跟手。代码中确认 0.6.0 在 SDL 采样线程逐帧等待鼠标 ACK；确认延迟会积压采样，触发 50 ms 的旧事件丢弃与重置。此为可复现的阻塞机制，实机卡顿的全部原因仍需更新后对照确认。

0.6.1 将键鼠 I/O 与采样分离，连续位移按 FlexInput 原生路径累积并在默认 500 Hz 节奏发布，不逐帧等待确认；直接使用其 HrWaiter，并保持绝对截止时间、长停顿不追赶发送、静止只发送一次归零帧。离散按键／滚轮和停止边界的确认留在 I/O 线程。另将曲线、One Euro 等纯模块改为直接编译原始 vendor 源文件，取消本地算法副本。

## 检查范围

- Rust 全量回归：143 项。新增延迟发送下 1000 个输入帧仍可处理且位移守恒、组合键／侧键／滚轮顺序、停止／换配置取消旧动作、超限分包、异步失败与全目标释放、过期输出不重放、原生流式发送策略、静止不刷空帧及绝对截止时间测试。
- 格式、应用三个 crate 的 Clippy（`--no-deps --all-targets -D warnings`）、TypeScript／Vite 构建。
- 无头界面回归 39 项，验证 JSM 导入、手柄导航、组合键／滚轮／侧键和 HID 组件设置；全部 Tauri 调用为模拟。
- 发布版 IPC：6 项通过，1 项实体手柄测试跳过。SDL 实体后端全部关闭。
- 111 个 vendor 文件、原始纯曲线／计时器文件、SDL、驱动载荷和许可证校验；新增上游发送源文件只作为固定参考，不引入 GUI 依赖。
- 安装包与便携包核对版本、资源清单、内嵌驱动四个载荷、桌面程序固定的引擎哈希和压缩包文件列表。

驱动仍为 HIDMaestro 2.0.1 发布包中的 2.0.0.2201，和 0.6.0 相同。配置格式和现有按键／体感设置保持兼容。`stats.output` 增加输出侧诊断，区分样本处理与报告发布；发布次数不代表游戏已接收。

## 实机边界

验证没有占用用户实际手柄、发送桌面键鼠、安装或替换驱动、修改 HidHide 或启动三角洲。阻塞/守恒测试使用模拟发送器和 ACK 延迟，不是游戏内延迟测量。真实顺滑度、Windows 实际接收率、长时间手感和游戏兼容性仍需用户手动验收。
