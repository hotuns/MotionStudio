# Motion Studio 0.9.1 验证记录

日期：2026-11-08，Windows x64。

## 改动与原因

- 动作名旁改用紧凑标签显示六种触发方式，连发另有标签，适配浅色／深色和英文，不增加操作焦点。
- Caps Lock 在上游 FlexInput 已有用途码，但 Studio 原有子集遗漏前端按键、配置校验与输出。现在使用前后端共用的 115 键清单，补齐标点、导航、锁定、小键盘、左右修饰键和 F13–F24；F12 继续保留紧急停止。
- Esc 原有输出可用，但录入时用于取消。选键入口移到第一排，弹窗与列表快捷录入新增「映射 Esc」，复用正常录入提交与租约清理，仍支持直接按 Esc 取消。
- 原始纯 HID 查询通过 FlexInput headless 接口暴露；新 API 保留原函数内容，仅增加可见性。上游键表之外的标准用途显式适配，对照现有 SDL 绑定核验。媒体／音量消费页按键没有放入键盘清单。
