# Motion Studio v0.19.5

- **一次分享一个游戏的全部配置。** 在「配置库 → 本地配置」选中游戏，点「复制整组配置码」，把 `MSG1.` 开头的文字发给朋友。对方在「输入配置码」里粘贴并预览，即可导入独立分组。默认配置、每份配置的层和游戏专用切换规则都会带过去。单份配置仍可使用 `MS1.` 码离线分享。
- **按游戏管理和切换配置。** 一个游戏可以保存多套配置，例如「步兵」和「载具」，每套配置可以有自己的「开镜」层。在配置库勾选已有配置即可批量归类，也可以为游戏指定默认配置、快捷键和光标切换规则。升级后可在「未归类」找到原先未分组的配置。
- **用贝塞尔曲线调节响应。** 游戏摇杆响应、摇杆鼠标、体感动作和体感加速支持拖动锚点与控制手柄，也可以按段输入 `cubic-bezier(x1,y1,x2,y2)`。
- **单独矫正实体右摇杆。** 在「游戏配置 → 摇杆 → 虚拟右摇杆响应」填入游戏的实际曲线，开启「矫正实体摇杆输出」，就能在关闭体感时使用补偿。

本版发布校验覆盖前端生产构建、引擎与桌面端编译、打包资源、更新签名和安装包 SHA-256。映射回归测试按维护者选择跳过，实际分享流程和游戏内手感留待手动验收。
