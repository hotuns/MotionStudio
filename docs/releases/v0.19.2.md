# Motion Studio v0.19.2

- **为观众录制按键和鼠标动作。** 在「设备与输入 → 悬浮显示与录制」选「仅 OBS」，复制地址，在同一台电脑的 OBS 中添加「浏览器」来源并粘贴。把来源放在游戏捕获上方，观众就能看到按键组合、鼠标按钮、滚轮和移动轨迹，玩家桌面保持清爽。选择「手柄和键鼠」还能同时展示手柄输入与映射输出。
- **桌面校对与录制可以同时使用。** 「仅桌面」适合自己检查键位，「桌面和 OBS」可以分别摆放桌面悬浮窗和录制画面。升级会沿用原来的桌面显示设置。
- **虚拟 PS5 DualSense 支持六轴传感器直通。** 在「游戏配置」将输出方式选为「虚拟 DualSense（PS5）」，在「体感 → 体感输出」选择「DualSense 传感器直通」并启用体感。支持 DualSense 体感的游戏或 Steam 输入可以读取经设备校准的三轴角速度和三轴加速度。直通支持开启键、暂停键和可选的三轴陀螺仪滤波。实体手柄需要同时提供两种传感器，虚拟 DualSense 使用 usbip-win2。
- 已有 DS4 直通配置可以直接将虚拟手柄切换为 DualSense。基础层和各配置层的直通目标会一同调整，已有启停键和滤波参数会保留。

已有 Windows 安装版可在「设置与组件 → 软件更新」升级。
