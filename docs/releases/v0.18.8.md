# Motion Studio v0.18.8

- **虚拟 PS4 传感器直通**。选择虚拟 DualShock 4 和 ViGEm 后端后，可在「游戏配置 → 体感 → 体感输出」选择「DS4 传感器直通」。Studio 将校准后的三轴陀螺仪、三轴加速度和采样时间写入 DS4 扩展报告，交给游戏或 Steam 输入处理。
- **使用现有体感开关和配置层**。可以用按住、切换和暂停键控制直通，也可以按配置层切换输出方式。暂停、采样超时或离开直通时会清零陀螺仪输出。普通按键和摇杆映射继续可用。

直通需要同时提供陀螺仪和加速度计的实体手柄接口，以及支持读取 DS4 传感器的游戏或输入层。Studio 随附 ViGEmBus 1.22.0。直通的坐标、灵敏度和滤波在接收端设置。

已有安装版可以通过「设置与组件 → 软件更新」升级。正式构建和签名校验纳入本次发布流程，实际游戏兼容性以实机验证为准。
