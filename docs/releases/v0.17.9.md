# Motion Studio v0.17.9

- 改善 HIDMaestro 虚拟 DS4 在部分游戏中的兼容性：采用与 ViGEm 相同的产品标识，保留原有映射、报告编码和输出频率。用户已在《三角洲》中确认慢速摇杆、体感转动的细碎跳动消失，1000 Hz 输出也正常；无需设置临时环境变量。
- 修复 ViGEm DS4 启动时误将暂时无接收请求当作致命错误的问题；持续刷新最新状态，并等待虚拟手柄接口完成枚举，避免与 HIDMaestro 键鼠混合输出时初始化失败。
- 增强 HIDMaestro 手柄输出诊断：记录提交间隔、交付确认和实际摇杆轴值，保留最近非中立输出，方便定位游戏内卡顿。

本版本仅提供 Windows x64 安装包；保留自动更新签名和校验文件，不提供免安装包。
