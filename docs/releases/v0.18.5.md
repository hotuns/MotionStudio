# Motion Studio v0.18.5

- **手柄映射详图**：在「游戏配置 → 动作映射 → 手柄映射概览」点击「查看具体映射」，围绕手柄查看动作名称、完整输入、输出按键和触发方式。同一按键的多个动作分别列出，组合映射显示在各成员旁；支持点击定位与编辑。编辑操作层时标明继承来源，并隐藏被覆盖或禁用的基础动作。
- **统一手柄输入监听**：需要选择手柄按键的设置统一提供输入框与「监听手柄输入」按钮，支持直接录入；两个控件保持垂直对齐。
- **输出保持**：键鼠动作和虚拟手柄数字映射增加「再次触发才停止输出」，可结合长按、双击与连发使用。停止映射、断连或开始录入时会清除保持状态。
- **操作层切换**：保留按住开启，新增按一下开启、再按一下关闭，并可设置关闭层输入与返回基础层输入。增加动作覆盖冲突预览和实时映射状态，便于查看当前输出与等待状态。
- **映射修复与界面调整**：修复组合键全部松开后快速再次按下可能漏触发的问题；编辑默认虚拟手柄布局中的单条映射时保留其余映射；游戏动作弹窗中的「组合输出」独占一行，避免被挤压。

映射详图展示当前草稿及当前编辑层，不代表运行中所有操作层的叠加状态。原有配置继续使用原来的按住切层和普通输出方式，新增保持与切换功能需要手动开启。

本版本由本机构建并签名，提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可通过顶部更新提醒，或在「设置与组件 → 软件更新」升级，已有配置继续保留。
