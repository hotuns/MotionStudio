# Motion Studio v0.18.9

- **手柄输入更新**。Windows 版随附 SDL 3.5.0 开发快照 `e21b424`。这一版包含上游对 GameSir Tarantula 8K 原生接口 `3537:103C` 的支持。该接口需要兼容的手柄固件，通过 USB 连接时可读取手柄上报的体感数据。[SDL 官方构建记录](https://github.com/libsdl-org/SDL/actions/runs/44651637592)
- **支持自行替换 SDL3 DLL**。完全退出 Motion Studio 后，可以备份并替换安装或解包目录下的 `resources/SDL3.dll`，然后重新启动。替换文件需要是兼容的 Windows x64 SDL3 DLL。

已有安装版可通过「设置与组件 → 软件更新」升级。
