# Motion Studio v0.18.4

- **三维悬浮手柄**：在「设备与输入」或「设置与组件」打开「三维悬浮手柄 → 显示悬浮手柄」，将实时输入页面的模型和动画显示在屏幕上，方便录屏或直播展示按键、摇杆、扳机、触摸及姿态动作。
- **显示设置**：支持选择显示器、屏幕四角、大小、不透明度和是否跟随姿态。悬浮窗透明、置顶、鼠标穿透，主窗口最小化后继续显示，设置自动保存。
- **修正摇杆方向**：修复三维模型中左右摇杆前后倾斜与实际输入相反的问题，覆盖五款内置模型。
- **显示状态恢复**：停止观察、断线或状态更新中断时，悬浮手柄恢复中立；三维图形不可用时自动切换为二维预览。

先开始观察输入或开启映射，悬浮窗才会显示实时动作。录屏建议使用显示器捕获；仅捕获游戏画面可能不包含这个独立窗口，游戏可使用无边框窗口模式。

本版本由本机构建并签名，提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可通过顶部更新提醒，或在「设置与组件 → 软件更新」升级，已有配置继续保留。
