# Motion Studio v0.19.4

- **按已知的游戏曲线补偿虚拟右摇杆。** 在「游戏配置 → 体感 → 输出与转角校准」选择分段曲线，按游戏内的实际响应添加、拖动控制点，也可以粘贴整张表。横轴是推杆量，纵轴是游戏转速占满杆转速的比例。体感和拨动输出到右摇杆时会按这条曲线反算推杆量。
- **摇杆鼠标可以直接改曲线。** 在「游戏配置 → 摇杆 → 摇杆鼠标」把半杆处的点向下拖，就能降低小幅推杆时的鼠标速度。旧配置沿用原来的指数响应，第一次编辑点时才切换到分段响应，也可以一键恢复原指数。
- **体感设置支持拖图调节。** 体感动作和自定义转动加速可以加点、拖点和删点。预设加速、平滑、低速截止、角度吸附和减速刹车可以拖动图上的参数标记。「快速转向」中的鼠标拨动也可以直接拖动 180° 释放终点来调整时间。

本版发布校验覆盖前端生产构建、引擎与桌面端编译、打包资源、更新签名和安装包 SHA-256。游戏内手感留待手动验收。
