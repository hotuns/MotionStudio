# Motion Studio v0.19.1

- **新增桌面键鼠输出显示。** 在「设备与输入 → 桌面悬浮显示」选择「键鼠输出」，可以看到映射实际发出的按键组合、五个鼠标按钮、横向和纵向滚轮，以及最近 300 毫秒的鼠标轨迹。按住的键保持点亮，短按松开后短暂保留。选择「手柄和键鼠」可以同屏对照手柄动作与输出。
- **修复快速拨动漏判。** 摇杆在一次轮询内推到外圈并回中也能触发拨动。斜向拨动使用同一采样中的完整方向，鼠标和虚拟右摇杆继续使用原有转角计算。
- **恢复角速度瞄准的自定义滤波。** 体感转鼠标和转虚拟右摇杆都支持 Rhai 脚本的三个阶段。已有配置中已启用的脚本会重新参与处理。
- **改善体感启停时的第一帧输出。** 体感鼠标从启用键按下的时间开始累计位移。体感输出到虚拟右摇杆时，玩家已推住的摇杆方向也能接续到第一份混合输出。

已有安装版可在「设置与组件 → 软件更新」升级。已设置的三维悬浮手柄会保留原有显示方式。
