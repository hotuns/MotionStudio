# Motion Studio v0.19.7

- **在游戏中测量摇杆响应曲线。** 选用虚拟手柄，保存并应用基础层配置，启动映射后打开「游戏配置 → 摇杆 → 虚拟右摇杆响应 → 在游戏中测量曲线」。Studio 会依次固定输出 100%、25%、50% 和 75% 的水平推杆量。用手柄标记准星经过同一参照物的起点和终点，即可得到各档相对转速。可选测 10% 和 90%，也可以单独重测某一档。确认后再将结果保存为当前配置的分段补偿曲线。
- **高灵敏度可以按多圈计时。** 每档开始前按面键左，在 1、3、5、10、20 圈之间切换。例如满杆测 10 圈、半杆测 3 圈，Studio 会按各自的平均单圈用时计算。可以直接使用平时的游戏灵敏度。
- **用手柄操作校准悬浮窗。** 转角校准和曲线测量都会在按钮上标出对应的手柄键。游戏保持前台时，按面键下开始试转或标记测量，按面键上保存。曲线测量中按面键右可停止本档推杆。

本版执行 Windows x64 正式构建、资源校验、更新签名和安装包 SHA-256 校验。按维护者安排跳过映射回归测试，游戏内表现留待实机验收。
