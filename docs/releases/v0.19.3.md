# Motion Studio v0.19.3

- **左右摇杆支持四向外圈。** 在「游戏配置 → 动作映射 → 手柄输入 → 摇杆」可以分别绑定外圈 ↑、↓、←、→，也可以点「监听四向外圈」推杆录入。例如，将「左摇杆外圈 ↑」绑定为按住 Shift，向前推入外圈就会奔跑，沿外圈转向右侧就会松开 Shift。
- 每个方向占 90°，共用该摇杆的外圈阈值和回差。原有整圈映射可以继续使用。方向外圈也可绑定虚拟手柄按键、配置层或切换配置的快捷键。
- **可以选择更新来源。** 在「设置与组件 → 软件更新」选择「跟随界面语言」、Sealos 或 GitHub。跟随语言时，中文使用 Sealos，英文使用 GitHub。手动选择会保存在本机。两个来源提供相同的签名 Windows x64 安装包。

已有 Windows 安装版可以通过原来的 GitHub 更新通道升级到本版。
