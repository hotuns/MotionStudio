# Motion Studio v0.19.6

- **一键修复 HidHide。** 停止映射或输入观察后，打开「设置与组件 → 组件管理 → 一键修复 HidHide」。缺少驱动时会启动官方安装包。驱动可用时会恢复 Studio 遗留的自动隐藏会话，并核验当前引擎的读取权限。需要重启时会给出提示。
- **改进 GameInput 手柄的自动隐藏。** Studio 通过 Windows 设备信息定位实体手柄。使用能唯一识别的 XInput USB 接收器时，映射期间会隐藏整只接收器，包括它提供的键盘、鼠标和厂商接口。停止映射后会撤销本次新增的隐藏规则。
- **打开体感页就能找到总开关。** 在「游戏配置 → 体感」顶部可以直接启用或关闭体感，并查看体感输出。启停按键、灵敏度和防抖参数按用途分组。
- **游戏配置页更适合宽屏。** 体感、摇杆、扳机和触控设置在工作区内居中，标签靠近对应控件。动作映射继续使用完整宽度，方便对照动作表和手柄预览。
- **在软件内管理驱动组件。** 打开「设置与组件 → 组件管理」可以查看 HidHide、ViGEmBus、HIDMaestro 和 USB/IP 的状态。选择卸载时会提示对当前配置的影响，并根据安装方式启动卸载程序或打开 Windows「已安装的应用」。
- **区分已卸载和等待重启。** Windows 已登记驱动删除、但仍需重启才能生效时，组件管理会显示「等待重启」。

本版执行正式构建、资源校验、更新签名和安装包 SHA-256 校验。映射回归与实机验收由维护者手动进行。
