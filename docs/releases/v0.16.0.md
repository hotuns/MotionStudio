Motion Studio 0.16.0 新增软件内更新。安装版和免安装版可以在「设置与组件 → 软件更新」查看、下载和验证后续版本。

- 游戏内转角校准悬浮窗会持续刷新手柄净转角。游戏锁定鼠标时，可使用悬浮窗提示中的快捷键开始、结束和保存校准。
- 右摇杆鼠标、体感鼠标与虚拟摇杆共用新的输出调度。可在「设置与组件」选择固定节拍或跟随显示刷新。
- 游戏动作录入悬浮窗可以新增动作并录入游戏键鼠，顶部配置选择器可以访问本地与社区配置。

首次升级到支持在线更新的版本，请从本页下载并安装，或完整解压免安装 ZIP。已有 Motion Studio 配置会保留。

Motion Studio 0.16.0 adds in-app updates for both the installer and the portable edition. Download this first update manually; future signed versions are available under Settings & Components → Software update.
