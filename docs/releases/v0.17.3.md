- 游戏内转角校准默认提供「试转 360°」。支持鼠标和虚拟右摇杆输出，可在悬浮窗直接修改校准值、按 1% 微调并再次试转，确认后保存。
- 原有水平和垂直手动测量保留在「更多校准方式」。测量结果会回填到试转界面，两个方式共用临时校准值。
- 校准界面说明鼠标和虚拟摇杆各自的调整方向，并提示摇杆 Flick 所需的线性响应曲线与关闭转向加速设置。
- 配套摇杆瞄准的三个参数移至对应开关下方，仅开启时显示。「摇杆最大转速」改名为「连续瞄准基础转速」，明确它与游戏「满杆角速度」校准值的区别。

已知待排查问题：部分虚拟 DS4 小幅度摇杆操作出现视角间歇停顿，原因尚未确认，本版未宣称修复。

本版仅提供 Windows x64 安装包，不提供免安装包。已有安装版可在「设置与组件 → 软件更新」升级。

- In-game angle calibration now opens with a 360° trial turn. Mouse and virtual right-stick output support editable calibration values, 1% adjustments and repeated trials before saving.
- Manual horizontal and vertical measurement remains under More calibration methods. Results fill the trial-turn value, and both methods share the temporary calibration value.
- Calibration explains the adjustment direction for each output mode and the linear response/disabled turn-acceleration settings needed for stick Flick.
- Companion stick aiming parameters now sit directly below their toggle and appear only when enabled. Stick maximum turn rate is renamed Continuous aim base turn rate to distinguish it from the game's calibrated full-stick angular speed.

Known issue under investigation: intermittent camera pauses during small virtual DS4 stick movements. The cause is unconfirmed and this release does not claim to fix it.

This release provides a Windows x64 installer only. Existing installations can update from Settings & Components → Software update.
