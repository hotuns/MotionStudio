- Chord mappings now wait 80 ms by default, adjustable from 0 to 500 ms. Completing a chord within the window cancels its individual mappings until all chord inputs are released. The new default applies to existing chords. Set the window to 0 ms to disable waiting.
- TOML profile import and JSM main and related file selection use the Windows file picker. JSM import still supports pasted text and conversion previews.
- Linear, natural, power, quadratic, sigmoid and jump gyro acceleration modes show their current multiplier curves. Custom control points remain editable.
- The layer controls sit to the left of Profile tools on the output-mode row. That row and the game configuration tabs stay at the top while scrolling.

This release provides a Windows x64 installer. Existing installations can update from Settings & Components → Software update.
