- Flick Stick 新增「转角缓出强度」和曲线预览。0% 匀速完成转身，100% 使用 JSM 的缓出曲线。旧配置默认保持匀速，新导入的 JSM Flick 配置使用 JSM 曲线。
- Windows 版使用官方 SDL 3.4.18。Apex 6 Pro 固件修复陀螺仪轴向后，本版移除了针对这款手柄的专用换轴补丁。

Motion Studio 0.16.0 的安装版和免安装版都可以从「设置与组件 → 软件更新」升级。

- Flick Stick now offers adjustable turn easing and a curve preview. At 0% the turn progresses at a constant rate. At 100% it follows the JSM easing curve. Existing profiles retain the constant rate, and newly imported JSM Flick profiles use the JSM curve.
- The Windows build uses official SDL 3.4.18 and removes the Apex 6 Pro gyro axis workaround following the controller firmware fix.

Both editions of Motion Studio 0.16.0 can update through Settings & Components → Software update.
