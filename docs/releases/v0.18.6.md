# Motion Studio v0.18.6

- **拨动角度吸附**：在「游戏配置 → 摇杆 → 拨动与扫动」选择四向（90°）或八向（45°）吸附，并调整 0–100% 强度。复用原生 JSM 初始角度吸附；外圈扫动保持连续。
- **仅拨动**：新增「仅拨动（关闭外圈扫动）」。保留初始拨动的转角释放，回中后可以再次拨动；配套摇杆瞄准独立设置。支持配置层覆盖、分享，以及 JSM 的 FLICK_ONLY、FLICK_SNAP_MODE、FLICK_SNAP_STRENGTH 导入。
- **JSM 风格体感默认值**：新建配置采用线性、1× 加速倍率，额外平滑、低速抑制、吸附和刹车默认关闭。基础鼠标计数改为上游默认的 40，仍需按游戏校准。体感页新增「JSM 线性」预设，保留当前灵敏度、坐标、游戏转角校准和自定义滤波。
- **统一中文术语**：初始转向使用「拨动」，沿外圈连续转向使用「扫动」，设置、帮助说明及搜索入口同步更新。
- **组件安装指引**：首次使用或启动映射时检查当前配置所需组件，支持一键依次安装缺少的内置组件并重新检测。取消或失败时停止后续安装，重试会跳过已完成项目；安装保留 Windows 管理员授权，不自动重启。虚拟 DualSense 提供 usbip-win2 官方安装入口。
- **组件状态与隐藏检测**：区分未安装、待启动、控制接口忙碌等状态；HidHide 自动隐藏不再依赖官方 CLI 是否安装。映射运行时复用当前隐藏会话状态，减少组件检查与映射会话互相占用。

已有配置中明确保存的灵敏度、校准值和响应参数保持不变；省略字段使用新默认值。拨动吸附和仅拨动默认关闭，需要手动启用。

本版本提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可通过顶部更新提醒，或在「设置与组件 → 软件更新」升级，已有配置继续保留。

验证范围：正式构建、资源完整性、更新包签名及文件哈希校验。按维护者要求，本次未运行自动化测试或实机测试。
