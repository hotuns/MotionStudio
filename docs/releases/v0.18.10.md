# Motion Studio v0.18.10

- **虚拟 DualShock 4 直通滤波**。在「游戏配置 → 体感」选择「DS4 传感器直通」后，可在「直通滤波」设置 0–120 ms 三轴平滑、按设备校准噪声底设置 0–5 倍噪声抑制，或启用原始角速度 Rhai 脚本。
- **沿用体感启停绑定**。直通支持按住开启、按键切换和独立暂停键。停止输出时会归零角速度并清理滤波历史。滤波逐样本执行，保留采样时间和校准后的加速度。旧配置默认关闭直通滤波。

已有安装版可通过「设置与组件 → 软件更新」升级。直通需要 ViGEm 虚拟 DualShock 4 及同时提供陀螺仪和加速度计的实体手柄接口。
