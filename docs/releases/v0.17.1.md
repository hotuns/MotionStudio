- 顶部工具栏新增「静止校准」，校准进度显示在状态栏。
- 在键鼠配置和兼容的虚拟手柄配置之间切换时保留已连接的虚拟手柄。键鼠配置将它置于中立状态，并暂停手柄反馈。
- 修复低输出频率下偶尔漏判 Flick 的问题。体感暂停期间 Flick 可继续，松开 Flick 自己的启用键则取消余下转角。Flick 的摇杆屏蔽同时作用于方向按键、普通摇杆鼠标和虚拟手柄映射。
- 修复配置层切换后残留的摇杆输出，以及阈值变化误触发体感切换或定角转身的问题。改善触摸板时序和输入积压后的恢复，受中断的转角校准会提示重新测量。
- JSM 导入在关闭体感时可保留独立 AIM 或 Flick，并保留同时配置的体感开启和暂停绑定。

本版提供 Windows x64 安装包。已有安装版可在「设置与组件 → 软件更新」升级。

- Start stationary gyro calibration from the toolbar and follow its progress in the status bar.
- Keep the virtual controller connected when switching between keyboard/mouse and compatible gamepad profiles. The keyboard/mouse profile leaves it neutral and suspends controller feedback.
- Recognize quick Flick gestures between output slots, keep Flick active during gyro pause, and cancel its remaining turn when its own enable control is released. Stick suppression also applies to direction bindings, ordinary stick mouse, and virtual controller mappings.
- Fix stale stick output and unintended toggle or turn edges during layer changes. Improve touchpad timing and recovery after an input backlog. An interrupted angle calibration asks for a new measurement.
- Preserve standalone AIM or Flick when importing a JSM configuration with gyro disabled. Import gyro enable and pause bindings together.

This release provides a Windows x64 installer. Existing installations can update from Settings & Components → Software update.
