- 工作台集中提供主要功能入口，新增「快速上手」引导。页面和配置弹窗统一样式，默认采用炭黑与亮绿配色的深色主题。
- 虚拟 Xbox 360 和 DualShock 4 支持逐项绑定、填入可编辑的标准布局，以及按配置层覆盖布局。原有标准映射会读入为可编辑的绑定。
- 改进同一输入上按住、短按、长按和双击的识别。键鼠动作和虚拟手柄数字映射都可设置触发方式，单项可开启「允许同时触发」。
- 输入轮询和输出频率可独立设置，默认均为 500 Hz。左右摇杆支持八向重叠，斜推可同时触发相邻方向，导入的 JSM 方向映射沿用这套规则。
- Flick Stick 缓出默认 50%，对应 JSM 的二次缓出，100% 使用更快的三次缓出。Flick 与配套摇杆瞄准共用体感输出和对应校准值。
- 游戏内转角校准改用 Windows 原生悬浮窗，便于在游戏前台查看实时校准读数。

本版起只发布 Windows x64 安装包。旧安装版可在「设置与组件 → 软件更新」升级。旧免安装版请退出后手动运行安装包，已有配置和本机设置仍可使用。

- The workbench brings the main tools together and adds a Quick start guide. Pages and dialogs share a desktop style with a charcoal and green dark theme by default.
- Edit individual virtual Xbox 360 and DualShock 4 bindings, fill an editable standard layout, and override layouts in layers. Existing standard layouts are loaded as editable bindings.
- Hold, tap, long press, and double press can share an input with improved gesture resolution. Keyboard, mouse, and digital virtual controller bindings can allow simultaneous triggers.
- Configure input polling and output rates independently, both defaulting to 500 Hz. Eight-way stick mapping supports adjacent directions on diagonals and preserves the direction behavior of imported JSM bindings.
- Flick Stick defaults to 50% easing, matching JSM's quadratic curve. At 100% it uses a faster cubic curve. Flick and companion stick aiming share the gyro output route and calibration.
- The in-game turn-angle calibration now uses a native Windows overlay for live readings while the game is in the foreground.

This release provides a Windows x64 installer. Existing installations can update in Settings & Components → Software update. If you use an older portable build, close it and run the installer manually. Your profiles and local settings are preserved.
