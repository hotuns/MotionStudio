# Motion Studio v0.18.1

- **触摸板滑动持续输出**：上滑、下滑、左滑、右滑识别后保持到手指抬起。使用「按住」触发时，手指停住仍会持续输出，抬手立即释放；同方向的双指手势在最后一根触发手指抬起时释放。
- **新增「按住暂停 Flick」**：位于「游戏配置 → 摇杆 → 共用启用与输出规则」，与「按住启用」互斥，设置其中一个会清除另一个。暂停会停止 Flick 和配套摇杆瞄准、取消剩余转角，并交还原始摇杆；暂停时摇杆已在外圈，则先回中再接受新的 Flick。
- **提高摇杆鼠标速度上限**：界面上限从 4000 提高到后端已支持的 10000 计数/秒，并明确显示单位和响应说明。响应值越大，中小幅度推杆越慢；1 为线性，满杆速度由「最大移动速度」决定。

升级保留已有配置值；新增 Flick 暂停输入默认不设置，摇杆鼠标不会自动提高速度。Flick 的开启／暂停互斥校验同时覆盖导入配置与配置层。

APEX 6 Pro 音圈触觉仍为实验性功能：拔插或切换连接后可能停止映射，连接稳定后需手动重新开始。

本版本提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可在「设置与组件 → 软件更新」升级。
