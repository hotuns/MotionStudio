# Motion Studio v0.19.0

- **玩家空间和世界空间**都可选择「转动」或「侧倾」。在「游戏配置 → 体感 → 方向与握持方式」设置。改变握姿时，手柄的陀螺仪和加速度计共同跟踪重力方向。
- **快速转向**支持「拨动／转动」「仅拨动」和「仅转动」。外圈转动使用 64 毫秒平滑窗口。输出到虚拟右摇杆时，体感与拨动合并输出，拨动时长按游戏满杆角速度计算。
- **一套瞄准设置**适用于新旧配置。原有按键映射和配置层可直接使用。旧版映射文本从「导入文本配置」转换，下拉选项在展开时立即显示。

升级后，角速度瞄准会跳过旧配置中的 Rhai 脚本滤波和边缘转向，自定义控制点按线性加速处理。这些设置仍保存在配置文件中。虚拟 DS4 传感器直通仍可使用原始角速度脚本。

已有安装版可在「设置与组件 → 软件更新」升级。本次发布的校验范围为 Windows x64 正式构建、中英文文案、内置资源、更新签名和文件哈希。
