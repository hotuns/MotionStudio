# Motion Studio v0.18.7

- **快速转向设置集中管理**：将拨动、转动与回中、拨动判定、配套摇杆瞄准和共用启用／输出规则合并到「游戏配置 → 摇杆 → 快速转向」同一个折叠项。展开后按用途以小标题分组，收起后统一隐藏。
- **开关与状态更清晰**：拨动／转动和配套摇杆瞄准的启用开关集中在顶部，共用摇杆选择。只开启配套摇杆瞄准时，收起摘要正确显示启用状态。
- **统一名称和搜索入口**：分组标题使用「快速转向」，内部动作使用「拨动」「转动」；帮助说明、映射概览、文档和中英文文案同步更新。搜索相关参数会展开快速转向并定位到对应控件。

本版调整设置布局与文案，沿用已有配置、转角校准和映射行为。拨动角度吸附仍只影响初始拨动，外圈转动保持连续。

提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可通过顶部更新提醒，或在「设置与组件 → 软件更新」升级，原有配置继续保留。

验证范围：正式构建、资源完整性、更新包签名及文件哈希校验。按维护者要求，本次未运行自动化测试或实机测试。
