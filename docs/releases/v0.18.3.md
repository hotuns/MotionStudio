# Motion Studio v0.18.3

- **八向重叠角度可调**：在「游戏配置 → 摇杆 → 摇杆方向映射」选择八向重叠后，左右摇杆可分别通过滑块或数字输入设置 0–90° 的斜向重叠角度。调大更容易同时触发相邻两键，调小更容易保持单方向。
- **区域预览与恢复默认**：实时显示单方向和双方向的范围，支持一键恢复原生约 36.87° 的判定。已有配置和 JSM 导入保持原来的默认范围。
- **随配置保存**：重叠角度支持配置层独立覆盖和恢复继承；切换角度时清理受影响的待触发手势，避免沿用旧方向的计时状态。

本版本提供 Windows x64 安装包、自动更新签名和 SHA-256 校验文件。已有安装版可通过顶部更新提醒，或在「设置与组件 → 软件更新」升级，已有配置继续保留。
