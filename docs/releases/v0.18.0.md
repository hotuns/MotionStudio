# Motion Studio v0.18.0

- 新增虚拟 DualSense（PS5）输出，使用 USB/IP 复合设备接收游戏的原生触觉音频。
- 新增「APEX 6 Pro 音圈触觉（实验性）」：将左右握把触觉音频转发给 APEX 6 Pro，适配有线 USB 和接收器接口。功能默认关闭，启动时检查设备型号、音圈能力和身份。
- 普通游戏震动和音圈触觉可分别设置强度；音圈模式由同一输出线程混合普通震动。界面显示接收音频帧、发送波形包、缓冲时长和错误信息。
- 复用固定版本 FlexInput 的虚拟设备及 USB/IP 音频处理，继续使用同一份已校验 SDL 运行时，保留原有逐样本体感输入。

使用方式：在游戏配置中选择 DualSense，再到「游戏震动与灯光」开启 APEX 6 Pro 音圈触觉。系统需要已安装的 `usbip-win2` 虚拟 USB 主控制器；本版不自动安装此驱动。

实验性功能范围与已知限制：

- 已有用户确认实体握把有震感，诊断也记录到音频接收和波形输出；仍需更多游戏、连接方式及固件反馈。
- 首版仅转发握把触觉，尚未转发原生自适应扳机效果和虚拟手柄扬声器声音。普通游戏声音请继续使用原来的耳机或扬声器。
- 拔插或切换连接后，音圈身份检查可能超时并停止映射。连接稳定后需手动重新开始映射，必要时重新选择实体接口；这条音圈故障分支尚未平滑自动重连。
- 停止时会尝试恢复马达模式，但模式命令没有硬件确认，不同固件的恢复效果仍需实际反馈。

本版本仅提供 Windows x64 安装包，附自动更新签名和 SHA-256 校验文件。已有安装版可在「设置与组件 → 软件更新」升级。
