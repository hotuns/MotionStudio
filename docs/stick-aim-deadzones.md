# 摇杆输入与 Flick 死区（0.10.0）

左右摇杆各有一套通用输入处理，直接使用 FlexInput 原生 device.source 的校准、死区、防回弹和扳机处理。普通摇杆鼠标、Flick／配套瞄准、方向动作、内外圈和虚拟摇杆读取同一份处理后输入。

在「游戏配置 → 摇杆」调整左右摇杆输入死区，以及 Flick Stick 和配套瞄准的参数。保存配置后按现有热更新流程应用。

原先 Studio 的 Flick 图把摇杆接到自定义引脚，绕过了原生物理输入预处理。0.10.0 改为正确连接原生输入流程；没有修改原始 RWS/Flick 算法，也没有增加一套独立的 Flick 中心死区算法。

| 参数 | 作用 | 位置 |
|---|---|---|
| 左／右摇杆输入死区 | 过滤回中偏移，重新缩放有效行程 | 游戏配置 → 摇杆 |
| 中心偏移与圆周倍率 | 校正中心、各方向最大行程 | 摇杆 → 高级摇杆校准 |
| 普通摇杆鼠标速度／响应指数 | 处理后的摇杆如何产生鼠标位移 | 摇杆 → 摇杆鼠标响应 |
| 配套瞄准倍率／最大转速／纵向比例 | 原生 RWS 配套瞄准角速度 | 摇杆 → Flick Stick 与摇杆瞄准 |
| 快推转身阈值 | 在处理后的有效行程上判断 Flick 外圈 | 同上 |

例如输入死区为 0.2 时，原始幅度 0.2 以内归零；原始幅度 0.6 经过原生缩放后为 0.5。若快推阈值为 0.8，用处理后的幅度与 0.8 比较。输入死区与快推阈值属于不同坐标范围，不要求输入死区数值小于快推阈值，也不会在编辑时偷偷互相截断。

回中仍漂移时，在「设备与输入 → 已应用配置的输入预览」对照原始值和处理后值，再调整中心与死区。预览显示正在运行的配置名称。录入动作与手柄操作界面继续使用原始输入。

高级校准沿用原生参数：左右中心偏移、各 72 个方向的圆周倍率、扳机最小／最大行程、数字扳机阈值、回差和松开防抖。默认数字阈值 0.1、回差 0.02、最小防抖 4 ms，由构建检查从固定 FlexInput 公共常量核验。全为 1 的圆周数组不额外修正。当前提供参数编辑与数组粘贴，没有另写自动圆周校准算法。

配置写入 [input] 的 deadzone_left、deadzone_right 等字段，支持配置层覆盖。旧文件缺少单侧值时：已开启普通摇杆鼠标的所选侧继承旧 [stick_mouse].deadzone，其他侧继承旧 stick_deadzone。旧值随后作用于整套共享输入流程。通过界面改变摇杆鼠标启用状态或所选侧时，会先固定两侧已有有效死区，避免意外改变手感。

配置层的按住触发仍使用基础配置的处理后输入；即使层内更改死区，也不会通过更改自身触发条件造成来回切换。JSM 左右独立输入死区可以直接导入到这两个原生设置。
