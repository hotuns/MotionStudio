# FlexInput 原生输入／输出接入核查（0.11.0）

固定来源为 FlexInput 0.16.9，提交 c69f53ad3bca4ed34ef5f2d63509addaa7c767be。Studio 提供配置、表单、配置层和会话生命周期；已有原生算法与设备报告优先直接调用。精确来源和 vendor 修改见 [flexinput-reuse.md](flexinput-reuse.md)。

## 本次补齐的运行路径

| 原生实现 | 当前接入 | Studio 适配 |
|---|---|---|
| engine/eval/device_cal.rs 完整物理源处理 | 中心／圆周／扳机校准、左右死区、防回弹、数字扳机回差与防抖 | [input] 参数、原始 FIFO 转引脚、处理后预览；各摇杆消费者统一读取处理结果 |
| engine/eval/modules/rws.rs | Flick、配套摇杆瞄准、普通摇杆鼠标积分 | 配置转图、输出目标与既有角度支付；文件恢复为原始版本 |
| module.vec_response_curve | 普通摇杆鼠标响应 | 旧指数转换成 129 个原生曲线点，有合成测试约束插值误差 |
| virtual/hidmaestro_device.rs | 原生手柄开通道、引脚处理、编码、提交与归零 | 打开受限会话创建的索引；不启用上游全权限辅助服务器 |
| virtual/windows.rs 的 VirtualXInput／VirtualDS4 | 原生 ViGEm 目标、报告、归零与通知接收 | 无界面入口返回原本被忽略的写入错误、读取 Xbox 槽位；不重写报告编码 |
| hidmaestro/orchestrator::node_diag | 本次创建的 XUSB 伴随接口就绪检查 | 准备和心跳失败时停止；其他手柄的全局接口数量不能证明本设备成功 |
| virtual::poll_outputs、devices::send 与 LedOut::due | 游戏震动／灯光回传 | 同一所选句柄、反馈新命令基线、暂停释放、独立强度与开关；不另写报告解码 |
| devices SDL 触点与 engine/eval/trackpad.rs | 单板双指、双板手势和接触输入 | 原始触点 FIFO、原生 route_touchpad、预览、接触触发器与会话基线 |

输入仍使用原始 FlexInput SDL provider，保留逐样本时间戳和按键／轴 FIFO。没有换成聚合轮询，没有增加 SDL 运行时，多传感器体感融合按要求排除。

## 输出选择与状态

「设置与组件」分别保存键鼠与虚拟手柄后端。默认键鼠仍使用 HIDMaestro；标准 Xbox／DS4 默认使用原生 ViGEm，需要 ViGEmBus。也可明确选择 HIDMaestro 手柄。旧设置缺少 gamepad_backend 时使用 ViGEm；不会因为一个后端创建失败而静默换成另一个。

两个输出路径作为同一个映射会话创建，确认虚拟手柄就绪后再完成自动隐藏验证。配置切换、录入、停止、断线和退出沿用既有释放保护。组合输出同时向 HidHide 提供 HID 与 ViGEm 的受保护标识，避免把虚拟手柄误当隐藏目标。

「检查虚拟手柄」显示正在运行的实际目标、后端和可用的 XInput 槽位。未开始映射、仅观察或配置选择键鼠时，明确显示没有运行中的手柄输出会话。草稿选择和驱动安装状态都不能代替创建结果。

HIDMaestro Xbox 预设主 HID 接口使用厂商用途，游戏主要通过 XInput 伴随接口读取，因此传统 joy.cpl 不一定列出设备。传统窗口保留为可选入口。ViGEm Xbox 须取得 0–3 的有效玩家索引，界面显示为 1–4。部分游戏只读取第一个槽位，界面提示停止后重新安排连接顺序。本次不自动停用、重排实体设备。

## 仍有明确边界的能力

- **键鼠传输**：使用原始 HIDMaestro 共享内存及报告契约。Studio 保留可报错、有界队列、释放确认、独立保护进程和 115 键目录；原始 Enigo 入口不能覆盖这些已有键位与错误处理要求，不能替换后丢失既有功能。
- **游戏反馈转发**：0.11.0 已接通原生虚拟反馈到同一个 SDL 选中设备，支持震动强度、灯光和会话暂停基线；实际硬件支持由接口能力决定。
- **触摸坐标／手势**：0.11.0 已接通逐事件触点与原生触摸板鼠标，支持移动、双指滚动、轻点、拖动及双板组合；触摸接触也可触发动作、体感与配置层。触摸分区编辑和额外手势仍未提供。
- **专用 HID provider**：保留原始解析器，运行输入选择 SDL。原生 HID 后端需先提供同样的样本时钟、FIFO 和溢出停止契约，不能直接改用聚合 poll。
- **DualSense 音频、专用蓝牙、Joy-Con 2、USB/IP、网络输入**：当前未启用，按独立设备或传输需求接入。
- **用户脚本**：固定上游没有供用户编辑的脚本运行接口，因此 Rhai 扩展由 Studio 实现；原有投影、滤波和曲线仍走 FlexInput。

自动检查限定为纯计算、模拟输出、无头浏览器及禁用物理后端的 SDL 合成输入。真实驱动枚举、实际手柄和目标游戏由用户验收，不把单元测试通过当成游戏已经接受虚拟设备。

0.11.0 的设置、原生调用位置和无真机验证方法见 [游戏反馈与原生触摸板](peripheral-feedback-and-touch.md)。
