# Motion Studio 0.3.0 验证记录

日期：2026-11-07，Windows x64。

本次接入固定 FlexInput 0.16.9 的高级体感功能，未接入多传感器融合。输入仍使用本应用 SDL3 适配器，输出仍使用本应用 SendInput／ViGEmBus 实现。

## 已完成

- 88 项 Rust 测试通过：8 项基础单元测试、19 项原有输入／输出回归、25 项高级体感、9 项配置／工作区、11 项引擎宿主及校准、16 项桌面服务。
- Clippy 对 motion-core、motion-engine、motion-studio 检查通过，无警告。
- TypeScript 类型检查和 Vite 构建通过。
- 4 项 release 引擎进程测试通过：SDL 合成传感器事件、热更新／重连等待／配置切换、无效 IPC 退出、高级校准命令错误处理。
- SDL 合成设备同时注入三条陀螺仪和三条加速度事件，保留各自时间戳并检查相同数值的样本不会丢失，传感器到右摇杆链路通过。测试关闭实体设备后端并且不发送系统输入。
- 浏览器界面使用 Rust 导出的默认配置与合成 IPC，验证六个分类、坐标／姿态、曲线控制点、One Euro、Flick 输出、体感动作、定角转身、游戏转角结果填入、设备校准保存和六面校准请求；1440×900、1024×680、浅色和深色主题检查通过，无页面异常及横向溢出。
- 79 份 vendor 来源文件、修补版 SDL 和两份官方驱动安装包的原哈希通过校验。上游 cc.rs 保持原哈希，提取副本来源及修改说明见 motion.md、THIRD_PARTY_NOTICES.md。
- release 输入引擎与 Tauri NSIS 安装包构建成功。

## 关键行为

专项测试覆盖 45° 握持时的玩家／世界转向、SI 加速度换算、过期及乱序加速度、横滚参与转向、姿态保持与归零、正前方重设、边缘持续转向、摇杆旋转推力不变、接管与相对回归、倾斜保持／切换／连发、Flick 与定角转身的角度结算、体感与 Flick 共享满杆余量、惯性释放、滤波及曲线有限值、测量固定基础比例、测量暂停／断流／饱和，以及六面校准方向拒绝。

重连或热更新的按键快照不触发切换或转身；已有外圈 Flick 摇杆等待回中。瞄准开启键不会重置独立的体感切换动作；按住暂停立即释放。测量期间修改配置会被拒绝，时序失效的结果不能填入配置。

## 人工验收范围

真实手柄轴向、长期漂移、无线丢包、实际游戏镜头转角、Flick 手感、不同游戏的摇杆响应与虚拟手柄识别，由用户手动验收。浏览器合成 IPC 检查不代表真实桌面或游戏的端到端验收，也没有本次真机延迟数据。

本次构建时旧版 0.2.1 仍在运行；未操作其设备会话，未运行需要占用全局输出互斥量的独立保护进程集成测试。该模块的纯清理单元测试已通过。测试和构建未安装驱动、修改隐藏规则或启动游戏。

使用新版前退出旧版实例，避免旧进程持有输出独占锁，并避免两个版本同时写入本地设置。旧 Motion Studio 配置由新版本自动补齐默认设置，新导出配置需由 0.3.0 及更新版本读取。
