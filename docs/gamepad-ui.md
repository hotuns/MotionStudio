# 用手柄操作界面

0.5.0 增加独立的界面操作模式。已经选择接口，或能自动确定唯一体感接口时，前台启动可以进入此模式，配置库为空也能操作。顶栏「更多工具 → 手柄操作界面」可手动开启，开启后顶栏的「手柄操作中」按钮可停用，偏好保存在本机。

进入时释放原有映射输出，改用关闭体感、没有动作的观察配置。只读取选中的实体接口，不创建虚拟手柄，不发送系统键鼠事件；切换所选接口时跟随新接口。无需先创建游戏配置。工作台会预览该接口的按键和摇杆，并显示「手柄操作中」；此模式不采集陀螺仪，展开采样数据时会说明这一点。断连或停止读取后，预览不再显示之前的输入。

| 控件 | 操作 |
|---|---|
| 方向键／左摇杆 | 移动焦点，按住方向可连续移动。 |
| A／B | 确认或编辑／返回或取消当前调整。关闭弹窗或收起展开菜单后，B 可从功能页返回工作台。 |
| X／Y | 编辑当前控件／保存配置。弹窗中不触发全局保存。 |
| LB／RB | 切换顶栏、内容和底部操作；弹窗内切换标题、内容和底部按钮。 |
| 右摇杆 | 滚动页面或弹窗。 |
| View | 聚焦顶栏的工作台入口，按 A 返回工作台。 |
| Menu | 快捷操作：继续游戏、保存、切换配置、停用导航。 |
| View + Menu | 前台暂停映射并返回界面；界面模式的实体录入中取消录入。 |

焦点使用醒目描边，按键提示和当前控件名称位于底部状态区，随保存／应用操作条一起排布。确认、返回和保存仅处理新的按下事件，长按确认不会重复创建或删除。方向有初始等待与重复间隔，摇杆有独立按下／松开阈值。

下拉框打开可用手柄选择的窗口。数值控件按 A 进入调整：左右一小步、上下十步，A 完成、B 还原。文本控件使用屏幕键盘，支持字母、数字、常用路径符号、大小写、空格、退格、清空和确认取消；已有中文会保留，也可以从配置导入中文名称。首次创建配置预填名称，允许直接选模板并确认。

导航限制在当前弹窗，关闭后返回原控件；应用内文件选择器使用同一组按键。系统安装器、UAC 和其他应用窗口由 Windows 管理，不属于本应用导航范围。

实体录入期间暂停导航，避免 A／B 同时操作界面。View + Menu 可以取消录入。失焦或断开后停止导航和长按重复；恢复时只建立基准，不重放旧确认。

Menu →「启用当前配置并继续游戏」才恢复实际映射，此后不再用这些按键导航本应用。F12 仍可停止。
