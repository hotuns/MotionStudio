# 自定义体感处理链（0.10.0）

在「游戏配置 → 体感 → 防抖与稳态」展开「高级：自定义处理链（Rhai）」添加滤波器。可以在编辑器编写代码、载入示例，或导入 `.rhai` 文本。每份游戏配置最多四个滤波器，支持启停、调整顺序、参数和配置层覆盖，随配置 TOML 导出分享。

「完成」更新工作台草稿；「保存配置」持久保存，编辑当前运行配置时会应用。源文件导入后作为代码副本写进配置，修改外部 `.rhai` 文件后需要重新导入。编辑和预览不会重新连接手柄或创建输出设备。

## 处理位置

处理链使用每条原始传感器事件及其时间，不依靠界面刷新频率，也不合并相同数值的样本。

| 阶段 | 输入与输出 | 与原有处理的关系 |
|---|---|---|
| 原始角速度 `raw_gyro` | 三轴角速度，°/s | 设备零偏、方向与安装校准之后，坐标投影／姿态估计之前 |
| 内置滤波之前 `before_builtin` | 水平／垂直瞄准角速度，°/s，z 为 0 | 坐标投影之后，静止抑制、平滑、曲线等处理之前 |
| 内置滤波之后 `after_builtin` | 处理后的水平／垂直角速度，°/s，z 为 0 | 内置稳态、曲线、角度吸附和反转之后，基础灵敏度、纵向比例和鼠标／虚拟摇杆换算之前 |

阶段始终按表格顺序执行。同阶段的多个脚本按列表顺序串联，后一个收到前一个的输出。原始阶段使用规范坐标：X 向前、Y 向右、Z 向下；后两阶段 X 为屏幕水平转向、Y 向下。姿态控制摇杆模式只经过原始阶段，另两个阶段用于角速度瞄准及体感旋转摇杆。

未启用的阶段直接使用原有路径。游戏转角测量会旁路整条自定义处理链，避免用户滤波改变测量结果。

## 脚本接口

代码必须定义 `process(sample, params)`，返回含三个有限数值的数组 `[x, y, z]`。第一版 API 为 `api_version = 1`。

```javascript
fn process(sample, params) {
    [sample.x, sample.y, sample.z]
}
```

`sample` 是本次调用的数据副本。修改它不会改变输入事件或采样时钟。

| 字段 | 含义 |
|---|---|
| `x`, `y`, `z` | 当前阶段的输入，单位 °/s；二维阶段忽略返回的 z |
| `dt` | 本次有效采样间隔，单位秒 |
| `host_ns`, `sensor_ns` | 原始主机、传感器纳秒时间戳；不可用的原始时间戳保持 0 |
| `raw_x`, `raw_y`, `raw_z` | 校准后、任何自定义处理之前的规范三轴角速度，°/s |
| `accel_x`, `accel_y`, `accel_z` | 校准后的加速度，单位 g，转换为与原始角速度一致的向前／向右／向下坐标；静止平放时 Z 约为 -1 |
| `accel_fresh` | 加速度是否足够新；没有有效读数时三个加速度字段为 0 |
| `stage` | `raw_gyro`、`before_builtin` 或 `after_builtin` |
| `components` | 原始阶段为 3，其他阶段为 2 |

`params` 包含编辑器的数值参数，均以浮点数提供。示例需要整数窗口时使用 `params.window.to_int()`。最多 32 项，名称使用字母、数字和下划线；值必须有限，绝对值不超过一百万。算法需要加速度时勾选「需要加速度计」；映射会检查接口能力，并等待有效加速度样本。

使用 `this` 保存每个滤波器私有的状态：

```javascript
fn process(sample, params) {
    if params.tau_ms <= 0.0 {
        return [sample.x, sample.y, sample.z];
    }
    if !this.contains("x") {
        this.x = sample.x;
        this.y = sample.y;
        this.z = sample.z;
    }
    let alpha = 1.0 - exp(-sample.dt / (params.tau_ms / 1000.0));
    this.x += alpha * (sample.x - this.x);
    this.y += alpha * (sample.y - this.y);
    this.z += alpha * (sample.z - this.z);
    [this.x, this.y, this.z]
}
```

为该示例添加 `tau_ms = 12`。内置的时间平滑示例已包含代码和参数；另有透传与中值滤波示例。它们用于演示接口，默认映射仍使用已有 FlexInput 算法。可以在同一脚本定义辅助函数，脚本顶层初始化在实例创建／重置时运行，每个样本只调用入口函数。语言语法见 [Rhai 官方文档](https://rhai.rs/book/)，入口调用和状态绑定使用[官方函数调用接口](https://rhai.rs/book/engine/call-fn.html)。

## 预览与运行诊断

「验证并预览」调用真实 Rhai 运行时，给当前脚本输入 300 个、500 Hz 的合成样本。可选择静止抖动、阶跃或连续转动，切换 X／Y／Z 查看输入与输出。预览只包含当前滤波器，不连接真实设备，不经过其他处理阶段，也不发送键鼠或虚拟手柄输出。

列表显示已应用配置的运行状态、上次执行耗时和峰值。修改代码与参数后需保存；预览结果不代表尚未应用的脚本正在游戏中运行。失败时显示诊断并旁路该实例，用该实例收到的输入继续后续处理。

- 语法和顶层初始化错误阻止保存／应用，包括尚未启用的配置层内已开启的脚本。
- 运行时错误、异常数值、超预算或过大的状态使该实例保持旁路；不会每个采样重复运行失败代码。
- 「重置脚本状态」清空私有状态并重试旁路实例，保留输入、输出设备及隐藏会话。
- 配置层切换时，修改了源代码、参数、接入阶段、加速度要求或启停状态的实例会重新创建；未改处理逻辑的实例保留状态，层内的重命名与重排也不会清空它。
- 保存／重新应用整份配置时，沿用现有热更新流程重建运行状态。
- 采样时钟中断会清空健康实例的历史；已经失败的实例继续旁路，直到明确重置或重新应用。

## 执行边界

Rhai 固定为 1.27.0，使用 Rust 内嵌运行时。接口只提供数值、参数与私有状态，没有文件、网络、进程或输入输出设备 API；不允许模块导入、匿名闭包和嵌套 `eval`。`print`、`debug` 不写入引擎通信输出。

脚本最多 32 KiB；整份配置序列化内容最多 256 KiB，为引擎消息保留空间。每个传感器样本的整条处理链共用 4096 次 Rhai 操作预算；单次调用还有 5 ms 时间保护。操作数不是 CPU 指令数，也不是固定耗时保证。执行限制遵循 [Rhai 的资源限制接口](https://rhai.rs/book/safety/max-operations.html)。

数组最多 128 项、映射最多 48 项、字符串最多 1024 字节；持久状态及顶层变量合计最多 512 个数据节点、嵌套六层。调用深度、表达式深度和函数／变量数也有上限。输出须为三个有限数值，绝对值不超过一百万 °/s。

500 Hz 输入每个周期约 2 ms。选择脚本时应观察运行耗时、处理 P99 和队列 P99，控制整条链的总成本。预览使用合成数据，真实设备与游戏手感仍需实际验收。
