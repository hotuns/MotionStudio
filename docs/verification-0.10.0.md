# Motion Studio 0.10.0 验证记录

日期：2026-11-08，Windows x64。

## 最终改动

- 统一接入 FlexInput 原生物理源预处理，覆盖中心／圆周／扳机校准、左右输入死区、防回弹、数字扳机回差与松开防抖。方向、内外圈、Flick／配套瞄准、普通摇杆鼠标和虚拟摇杆共用处理结果，基础层激活保持独立稳定。
- 原始 RWS 文件恢复为固定提交的原文，SHA-256 fd7e3f0d1a07eaff77c40e24bdde560fc7a43b69e6ccfb549a467e2ccf393c96。没有独立 Flick 死区补丁。普通摇杆鼠标使用原生向量曲线与 RWS 积分。
- 手柄输出直接使用原生 HidMaestroDevice、VirtualXInput／VirtualDS4，移除 Studio 手柄报告编码。保留原报告构建，额外暴露写入失败和 Xbox 槽位供生命周期处理。补齐 DS4 模拟扳机与 L2／R2 数字状态。
- 键鼠与手柄后端独立设置，默认 HIDMaestro 键鼠配合原生 ViGEm Xbox／DS4；没有静默回退。HID Xbox 检查自身 XUSB 接口，ViGEm Xbox 检查有效玩家槽位，创建失败不进入输出已启用。
- 「检查虚拟手柄」显示实际运行设备／后端／槽位，传统 joy.cpl 保留为可选入口。两个输出路径共用隐藏、录入、释放和停止会话。
- 可选 Rhai 处理链支持三个逐样本接入阶段、独立状态与参数、排序启停、源码编辑／导入、真实运行时合成预览、故障旁路和重置。固定上游缺少用户脚本接口，Studio 扩展不替代原有体感算法。
- 语言选择固定左下角，保留未保存草稿；配置切换支持手柄单键／最多四键组合，与键盘共享目标和返回历史。录入保持设备与隐藏连接，等待全部松开后恢复输出。

## 实机验收范围

用户反馈 0.9.1 在「输出已启用」时仍看不到 Xbox；真实游戏失败没有在本机自动复现。本版修正原生输出接入、实际就绪检查和检查入口，提供标准 ViGEm 路径。真实驱动枚举、槽位、游戏是否接受输入以及长期手感，仍由用户使用最终包验收，不声称已通过三角洲实机测试。

当前仍未路由实体手柄的震动／灯光反馈，未接入触点坐标／手势、专用 HID 逐样本 provider、DualSense 音频、USB/IP 和网络。多传感器体感融合按用户要求排除。详细边界见 [原生接入核查](native-input-output.md)。
