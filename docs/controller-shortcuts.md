# 用快捷键切换游戏配置

在「自动切换 → 快捷键切换」选择目标配置。键盘和手柄可以分别绑定或清除，共用同一个目标。触发一次切到目标，松开后再触发一次返回切换前的配置。将目标设为「不启用」可停用两种快捷键。

## 用左摇杆外圈切换

1. 在「手柄快捷键」点「使用左摇杆外圈」。
2. 点「保存手柄快捷键」。
3. 运行映射或观察时，把左摇杆推入外圈即可切换。让摇杆退出外圈，再推入一次即可返回。

摇杆内外圈沿用当前运行配置基础层的摇杆校准、死区、外圈阈值与回差。持续留在区域内只触发一次。两份配置可以有各自的外圈设置，切换后以新配置的基础层为准。

## 选择或录入

- 手柄支持按键、扳机、摇杆方向、摇杆内外圈、触摸板按下和接触。可以手动搜索输入，最多组合四项。组合需要同时满足各输入条件。
- 连接手柄后也可录入。普通按钮、扳机、触摸和方向使用「按键与方向」。要录内外圈，选择「摇杆内外圈」，再点「监听手柄」。动作结束并松开后检查录入结果，点击「保存手柄快捷键」。
- 键盘可从列表选择单键，或直接录入单键及带 Ctrl、Alt、Shift 的组合。Esc 可从列表选择，录入时按 Esc 会取消。主键区 Enter 与数字小键盘 Enter 在全局快捷键中共用同一个绑定。
- 升级时保留既有键盘和手柄快捷键。默认键盘绑定为 F9，手柄为空。只想用手柄时，可点「清除键盘快捷键」。

F12 用于紧急停止，Windows 键与系统保留组合由 Windows 处理。View + Menu 用于进入手柄界面操作。快捷键会与游戏动作同时响应，原有映射仍会收到输入。

## 生效时机

录入时暂停游戏输出和自动切换，保留当前输入连接、虚拟设备和自动隐藏会话。完成后等手柄松开、摇杆回中再恢复映射。Esc、窗口失焦或离开页面会取消本次录入。空闲时录入手柄快捷键会先启动观察。

快捷键监听当前选中的实体手柄。界面导航、校准、游戏转角测量和录入期间暂停快捷键。输入引擎直接记录按下或进入区域的事件，持续按住只切换一次。切换成功沿用游戏内配置提示。

这是本机设置，保存在 `settings.json` 的 `shortcut_key`、`shortcut_pad` 与 `shortcut_profile` 中。
