# Motion Studio 0.8.1 验证记录

日期：2026-11-08，Windows x64。

## 修复内容

设备与输入、游戏配置右侧预览以及工作台共用的 `Controller` 组件仍使用旧 JSM 输入标识（如 `S/E/W/N`、`L/R`、`UP`），而实时状态和动作配置使用 `south/east/west/north`、`left_shoulder/right_shoulder`、`dpad_up` 等规范名称。结果是状态已经收到，SVG 的按下、绑定、选中及点击目标却无法匹配。

本版统一这些标识，增加编译期按键类型限制，补传扳机的按下状态；摇杆区域动作也会显示对应摇杆的绑定指示。已报告的扩展键 2 保留可见，肩键等不规则 SVG 控件按边界框响应点击，避免必须点中细线或狭窄填充。输入、映射、体感和输出算法不变。

## 已完成的检查

- 修复前，以模拟输入按住 A，设备页 SVG 未出现按下样式，回归用例稳定失败；修复后同一检查通过。
- **8 项专项无头界面流程通过，0 页面错误**：设备页按下／松开；全部面键、肩键、方向键、系统键、摇杆按下及已报告背键；ABXY 同时按住；双扳机；游戏配置全部标准按键；点击预览定位准确动作；浅色／深色视觉检查；其他设备状态不会点亮当前手柄。
- **16 项动作与录入回归流程通过**，覆盖组合、滚轮、侧键、取消录入、失焦、手柄组合、快速按键遥测、搜索及紧凑布局。
- TypeScript 类型检查、Vite 生产构建通过。翻译目录仍为 1,213 条，源文案覆盖和占位符校验通过。

本版没有修改 Rust 输入／输出逻辑；此前 0.8.0 的内核与生命周期验证记录保留在 [verification-0.8.0.md](verification-0.8.0.md)。版本元数据统一更新至 0.8.1。

## 发布验证

- 静态 CRT 引擎、桌面程序和 Windows x64 NSIS 安装器构建通过。产品版本为 0.8.1。
- 发布版 IPC **6 项通过、0 失败，1 项实体设备检查跳过**。此前运行中的用户映射占用输出锁，用户关闭应用后补跑全套用例；独立保护进程的 EOF 和心跳超时检查通过。没有强制停止用户进程。
- PE 核验：引擎仅延迟导入同一份 SDL3.dll，桌面程序无 SDL 导入。142 个 vendor 文件及固定 SDL／驱动资源哈希校验通过。
- 核对桌面程序内固定的最终引擎哈希、四个 HIDMaestro 内嵌载荷、功能标记、安装包／便携包的版本和哈希、归档中的使用说明及许可证。产物校验值保存在 `artifacts/checksums.json`。
- 原有 0.8.0 产物保留，新版文件使用 `MotionStudio-0.8.1-*` 名称。HIDMaestro 驱动版本保持 2.0.0.2201，无需重装驱动。

所有界面检查使用模拟状态和无头浏览器，没有占用实体手柄或发送桌面输入。真实设备可在「设备与输入」开始观察或运行映射后，逐个按住并松开 ABXY，再在「游戏配置」查看同一预览确认。
