# HIDMaestro 输出

Motion Studio 0.10.0 默认键鼠后端使用 FlexInput HIDMaestro；手柄单独选择，默认原生 ViGEm，也可选原生 HIDMaestro。输入使用 FlexInput SDL provider 逐事件接口。完整接入与边界见 [原生输入／输出核查](native-input-output.md)。

## 使用

1. 打开「设置与组件」，确认「键鼠输出后端」选择 **HIDMaestro · FlexInput 原生 HID 输出**。
2. 在 HIDMaestro 卡片点击「安装内置组件」，接受 Windows 管理员授权。安装会在本机创建非导出的专用签名密钥和 `Motion Studio Local Driver Signing` 证书，信任该证书并安装内置 UMDF2 驱动。不会自动重启系统。
3. 选择「虚拟手柄后端」；ViGEm 需要另装 ViGEmBus。回到游戏配置，选择键鼠输出，或 Xbox 360／DualShock 4，再开始映射。首次创建虚拟设备会请求一次管理员授权；同一引擎会话复用辅助进程，正常暂停和配置切换不重复提升权限。
4. F12、停止、断开及应用退出均会释放输出。若辅助进程或驱动失效，映射暂停并报告原因；不会静默切回 SendInput。

「SendInput / ViGEm · 兼容模式」保留原输出路径，切换前须停止映射或观察。输出后端保存在本机设置，不写入游戏配置，因此旧 TOML 与 JSM 导入结果继续使用原格式。旧设置缺少该字段时默认选择 HIDMaestro，需要先安装驱动。观察和手柄操作界面不创建 HIDMaestro 设备，也不请求提升权限。

## 覆盖范围

| 功能 | HIDMaestro 路径 |
|---|---|
| 普通键、组合键 | HID 键盘报告，先修饰键后普通键；释放顺序相反 |
| 体感／摇杆鼠标 | 相对鼠标 HID 报告，保留原小数残差；大位移分包，不截断丢弃 |
| 鼠标按钮 | 左、右、中、侧键 1、侧键 2 |
| 滚轮 | 垂直／水平，支持 Ctrl 等修饰键组合及原有持续滚动 |
| Xbox 360 | HIDMaestro XUSB companion，GIP 状态及输入门铃 |
| DualShock 4 | 原生 HID，完整标准按键、双摇杆、双扳机、方向键和触摸板点击 |

键盘采用上游固定描述符，支持最多同时按下 **6 个普通键**，Ctrl／Shift／Alt 另计。超出时明确报错并清理输出，避免漏键。0.11.0 已接入游戏震动／灯光回传；未增加 DualSense 类型、绝对鼠标或多传感器融合。

停止映射后键鼠和手柄归零，虚拟设备可保持连接，供同一引擎会话复用；退出或重启引擎后由辅助进程移除。兼容模式启用前会结束原 HID 会话。输入枚举和 HidHide 列表会排除这些虚拟设备，避免回读和误隐藏。

## 实现与固定版本

客户端来自 [FlexInput c69f53ad](https://github.com/x-iso/FlexInput/tree/c69f53ad3bca4ed34ef5f2d63509addaa7c767be/crates/hidmaestro)，保留共享内存、原始报告编码、设备编排、所有权声明与驱动签名／安装实现。未引入其 GUI、USB/IP、蓝牙接管、HidHide 管理或完整特权 RPC 服务。

内置驱动来自 HIDMaestro v2.0.1 发布包，驱动 INF 版本为 `2.0.0.2201`，两个 DLL 为 `2.0.0.0`，与该固定客户端一致。DLL、INF、模型和许可证均验证了固定 FlexInput Git 树的 blob SHA，再记录 SHA-256。二进制嵌入引擎，随运行资源清单校验；不要求 .NET、WDK 或运行时联网下载。

只在用户点击安装入口时安装缺失驱动；设备创建不会安装或升级驱动。已安装不同版本、安装不完整或版本握手失败时停止并报告，避免覆盖另一款应用使用的 HIDMaestro。此版本没有提供强制卸载、重装或清空其他应用设备的入口。

特权辅助进程通过每次启动随机命名的本地管道通信，双方核验对端 PID，拒绝远程连接和任意配置描述符。它仅接受心跳、三个固定手柄目标与关闭指令。设备使用 `MS` 身份前缀和 `MotionStudioDeviceId`，与 FlexInput 的 `FX` 及所有权字段隔离；分配索引时遵守 HIDMaestro 的机器范围索引声明。

引擎累计连续鼠标位移，在固定 500 Hz 时隙或 FlexInput 显示时钟指定的时隙统一提交。开启「设置与组件 → 输出跟随显示刷新」后，显示同步生效时每帧安排四个时隙。普通位移在 I/O 循环直接发布，从移动转为静止时仅发送一次零位移报告。

按键、侧键、滚轮和释放边界在独立线程确认交付。确认期间的新位移按队列顺序等待，保留短按和组合键顺序。停止或换配置会优先取消排队的旧位移，再发送中立状态并等待完成。辅助进程持有同一设备的中立释放报告和驱动 owner pipe。引擎退出、管道断开或 2 秒失去主运行循环心跳时归零并移除设备。辅助进程被强制结束时，驱动 owner watch 负责发送键鼠释放报告，XInput companion 随其创建句柄关闭。

诊断中的 `stats.output` 记录报告发布数、合并位移次数、排队数量、最大排队时间和边界等待时间。其中 `direct_motion_reports` 记录 I/O 循环直接发布的位移报告数，统计范围截至引擎写入驱动共享区。0.6.1 的驱动包与 0.6.0 相同，已经安装且就绪时不需要重新安装。

辅助进程在设备清理结束前持续持有输出互斥量，后继映射不能越过未完成的清理。普通键鼠与虚拟手柄的停止由自己的 HID 设备完成释放，不向 SendInput 发送替代释放事件。租约确认以异步方式处理，避免定期心跳阻塞体感输出。

## 验证边界

开发验证使用报告编码测试、模拟管道、模拟输出、关闭实体输入后端的 SDL 事件、IPC 回归及无头浏览器。未在开发过程中实际安装驱动、创建系统虚拟设备、发送桌面键鼠、占用实体手柄或启动游戏。

驱动安装、Windows 中虚拟设备枚举、停止／强制终止后的真实释放、长时间体感手感及三角洲兼容性均需真机验收。HIDMaestro 是虚拟 HID 输出，不保证游戏接受；官方也说明虚拟设备可被反作弊识别。[HIDMaestro 已知边界](https://github.com/hifihedgehog/HIDMaestro#known-limitations)

0.10.0 HIDMaestro 手柄使用原始 HidMaestroDevice 开通道、引脚处理、编码与提交；Xbox 须通过本设备 XUSB 就绪检查。传统窗口可能不列出 XInput 伴随设备，请用「检查虚拟手柄」的实际运行状态。

游戏反馈回传与原生触摸板见 [0.11.0 使用说明](peripheral-feedback-and-touch.md)。
