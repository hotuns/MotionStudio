# 导入 JSM 配置

在「游戏配置」或「配置库」点击「导入 JSM 配置」。选择文件或粘贴文本，点击「预览转换」，核对报告后创建一份可编辑的 Studio 游戏配置。导入完成后，手动启用输出。

点击「选择 JSM 文件」或「添加关联 JSM 文件」会打开系统文件选择器。支持 .txt、.jsm、.cfg、.conf，以及 UTF-8、带 BOM 的 UTF-16 LE／BE 和中文 GB18030／GBK。

## 轻拉和全拉

右扳机轻拉开镜、全拉保持开镜并开火，可以导入以下配置。

```text
TRIGGER_THRESHOLD = 0.25
ZR_MODE = NO_SKIP
ZR = RMOUSE
ZRF = LMOUSE
```

`ZL` 和 `ZLF` 对应左扳机轻拉和全拉，`ZR` 和 `ZRF` 对应右扳机。动作列表里可以继续编辑每个绑定，也可以为手动创建的配置选择这四个输入。模式、轻拉阈值和快拉时间窗位于「游戏配置 → 扳机」，全拉点使用校准后的最大行程。

转换支持 `NO_FULL`、`NO_SKIP`、`NO_SKIP_EXCLUSIVE`、`MAY_SKIP`、`MUST_SKIP` 及后两种的 `_R` 变体。`NO_SKIP_EXCLUSIVE` 在全拉时释放轻拉动作。原配置没有启用全拉模式时，转换会保留全拉绑定并提示在 Studio 启用对应模式。

## 转换成 Studio 配置

主文件引用 `GyroConfigs/Aim.txt` 等文件时，在导入窗口点「添加关联 JSM 文件」选中 `Aim.txt`。转换按引用位置合并一层静态文件。文件数量上限为 16 个，合计及展开后均不得超过 512 KB 和 4096 行。报告标明每行的来源文件。

之前保存的 JSM 原文配置也可以转换。在「导入 JSM 配置」中选择旧版 TOML 文件，预览后另存为新配置，旧文件保留。输出和透传有差异时会显示提示。

| JSM 内容 | 转换方式 |
|---|---|
| 普通键鼠绑定，如 `S = SPACE` | 转为按住输出，支持常用键盘键、Ctrl／Alt／Shift、鼠标五键、四向滚轮。F12 保留为紧急停止。 |
| 明确标注 StartPress 的多输出，如 `S = CONTROL\ K\` | 转为最多四个成员的同时输出。 |
| `L,S`、`L+R`、`UP*RIGHT` | 转为同时按住组合；前两种标为需要核验，原按下顺序／同时按压时间窗不保留。 |
| JSM Studio 注释 | 保留配置名称和可匹配的普通动作中文名；以实际命令为准。 |
| `GYRO_SENS`、`MIN/MAX_GYRO_SENS` 与阈值 | 基础灵敏度、纵横比例、反转、1–4 倍快速转动倍率。无法表达的零轴或独立纵横加速会报告。 |
| `REAL_WORLD_CALIBRATION`、`IN_GAME_SENS` | RWC / IN_GAME_SENS 转为每度鼠标计数；系统鼠标速度和实际游戏转角需核验。 |
| `GYRO_ON/OFF`、`NO_GYRO_BUTTON` | 常开、关闭、按住开启与暂停。在 `GYRO_ON=NONE` 基础上，单键 `GYRO_ON`／`^GYRO_ON` 可转为按住／切换开启。冲突规则会报告。 |
| `GYRO_TRACK_X/Y`、`GYRO_TRACKBALL` | 转为横向／纵向惯性体感按键。 |
| 坐标与轴向 | LOCAL、PLAYER／PLAYER_TURN、WORLD／WORLD_TURN、默认俯仰偏航、本地横滚和标准／反转。玩家／世界模式需要加速度计。 |
| 平滑和曲线 | 支持范围内的时间平滑、衰减平滑、One Euro、角度吸附、低速截止、减速刹车；六类 ACCEL_CURVE 及对应参数。算法或区间差异会提示。 |
| 摇杆 | NO_MOUSE 的原生八向重叠判定和一个摇杆的 AIM／FLICK、方向绑定、统一／分侧死区与部分 Flick 参数。方向绑定在输入死区之外立即响应，斜推同时触发相邻两键；外死区和其他模式仍需核验。当前关闭体感时，共用启用开关的 AIM／FLICK 不会被强行启用。 |
| 扳机 | 左右轻拉和全拉、`TRIGGER_THRESHOLD`、`TRIGGER_SKIP_DELAY`、双段模式及完整标准虚拟手柄透传。 |
| 标准 Xbox／DS4 布局 | 完整的标准按钮、左右摇杆和扳机会导入为显式手柄映射。部分或重排布局仍保留在导入报告，可在动作映射中手动重建。 |

报告显示原行号、原文、状态和原因。后面的赋值覆盖前面的，RESET_MAPPINGS 清除之前的配置；即使后一个绑定不支持，也不会偷偷保留前一个过期绑定。

轻按／长按（`E = C Z`）、双击、普通键的切换／瞬按／释放／连发、复杂多事件、按住切换设置、区域鼠标、复杂手柄重排、原始 DS4 传感器转发和未知扩展需要手动补配。运行程序、动态加载配置、SLEEP、校准和驱动等命令只出现在转换报告里。

差异项会标为“需要核验”。输出、坐标、开关或校准等关键体感项不能迁移时，保留其余动作并关闭体感，避免非预期鼠标移动。核验后在「游戏配置 → 体感」手动开启。转换结果保存为 Studio 原生动作与调校参数。

语法依据：[JSM 文档](https://github.com/JibbSmart/JoyShockMapper#commands)和本机 JSM Custom Curve 的配置及实现。转换器在 crates/engine/src/jsm_import.rs，不依赖旧项目目录。
