## 验证边界与手动验收

自动检查未占用实体手柄、发送桌面输入、安装或替换驱动、修改真实 HidHide 规则，也未启动游戏。验证过程未关闭用户的应用或中断用户的手柄会话。测试通过说明配置、状态机、事件接口和受保护生命周期符合契约，不能替代真实设备与游戏体验验收。

建议按以下顺序验收：

1. 查看版本 0.8.0。在「设置与组件」切换 English／简体中文，编辑一项未保存设置后再切换，确认内容保留；用手柄进入设置和选项窗口。
2. 开始映射，进入动作录入，确认虚拟手柄保持连接；完成后松开手柄、让摇杆回中，确认自动恢复；分别录入组合键、滚轮和侧键。
3. 添加外圈 Shift 奔跑；斜推、在边界附近移动和回中。分别验证短按、长按、双击、按下／松开触发及可选连发。
4. 基础层把 LB 映射鼠标右键，创建 LB 按住层并降低灵敏度。按住、松开切换，检查开镜键、连续体感和未修改动作；同时按住两层验证明确优先级。
5. 停止后检查隐藏恢复；再启动、断开、重连、F12 停止，确认实体与虚拟手柄可见性符合预期。不要把用户原有隐藏项恢复误认为应删除。
6. 在「自动切换」预览提示，再在窗口或无边框全屏游戏检查实际成功切换提示、所在显示器、位置和持续时间。真正独占全屏可能覆盖普通系统窗口，本版不保证该场景显示。
7. 验证体感和摇杆鼠标实际手感、长时间运行、设备拔插和目标游戏的虚拟手柄识别。HIDMaestro 驱动仍为 2.0.0.2201，无需因本次应用升级重新安装。

基础震动回传、实时触摸坐标分区、专用原生 HID provider、DualSense 音频／自适应扳机等仍在明确的后续候选中；未把编译源码等同于运行接入。按用户要求，不加入多设备体感融合。
