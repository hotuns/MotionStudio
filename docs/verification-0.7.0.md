# Motion Studio 0.7.0 验证记录

日期：2026-11-07，Windows x64。

本版把通用输入切换为固定 FlexInput 提交的 SDL provider，在聚合之前增加原始事件接口，保留双时间戳、相同读数及按键/轴事件顺序。Studio 保留设备 DTO、来源分类和生命周期适配。节点输出定义来自上游 modules；输出通过原始 VirtualDevice 契约和引脚布局进入现有受保护传输。

## 已完成的自动检查

- Rust：208 项通过，包含新接入设备模块的 60 项纯测试、节点描述测试和 4 项输出契约回归。覆盖原始事件 FIFO/溢出、SDL 内部事件转译保留、组合键/侧键/滚轮、位移守恒、报告转换、异步故障释放、重连和配置切换。
- 应用三个 crate 的格式检查、Clippy：`--locked --no-deps --all-targets -D warnings`。
- TypeScript/Vite 构建，以及 39 项无头界面流程。覆盖 JSM 导入、组合键、滚轮、侧键、手柄导航、配置和 HID 组件交互；Tauri 调用均为模拟。
- 新增源码中 24 个原始文件逐个核对固定 Git 树 blob，6 个新增 headless/build/event API 文件单独记录；总计校验 141 个 vendor 文件，保留原始与移植后哈希。
- 构建检查 SDL DLL、x64 导入库和原生驱动载荷哈希，检查 PE 延迟导入，并拒绝静态/源码 SDL 功能。Rust SDL 绑定与原飞智修正共用同一个 SDL 3.4.18 DLL。
- 引擎发布构建将静态 CRT 设置应用于全部目标依赖，包括 hidapi 的 C 源码；使用独立目标目录，避免与桌面动态 CRT 缓存混用。

- 发布版 IPC：6 项通过，1 项实体手柄检查跳过。测试使用最终静态 CRT 引擎，SDL 实体后端全部关闭；两次输入会话重建及传感器开关检查通过。

- 安装包和便携包校验覆盖产品版本 0.7.0、资源清单及哈希、桌面程序内固定的最终引擎哈希、四个内嵌驱动载荷、输入 provider 元数据及压缩包内的文档/许可证列表。

## 接入边界

- 当前活动输入是 FlexInput 的全 SDL 路径。原生 HID 解析器虽已编译，其专用轮询 provider 尚未启用；需要同样的逐样本时间戳接口后才能切换。
- 输出契约和布局直接复用；原生 HIDMaestro 客户端继续复用既有 SDK 子集，生命周期和错误保护仍由 Studio 适配。SendInput/ViGEm 兼容传输保留，不宣称整个 virtual crate 已迁入。
- 基础震动回传、网络、专用蓝牙、Joy-Con 2 专用后端、复合 USB 音频触觉和多设备体感融合未启用。
- 配置 schema 和 IPC 版本保持兼容；HIDMaestro 驱动仍为 SDK 2.0.1 中的 2.0.0.2201，不需要因本版重新安装。

自动检查没有占用实体手柄、发送桌面键鼠、安装或替换驱动、修改 HidHide 或启动游戏。合成 SDL 测试关闭实体设备后端，在同一进程重建两次会话，检查三条体感样本（包含相同读数）、原始时间戳、快速按下/释放、摇杆及传感器开关。实际体感/摇杆鼠标手感、物理重连和游戏识别仍由用户手动验证。
