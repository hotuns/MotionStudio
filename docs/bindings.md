# 游戏配置与组合键

「游戏配置 → 动作映射」统一管理按键动作、体感动作和定角转身。摇杆、扳机、触控和体感页设置输入识别与手感。五页共同保存到一份 TOML。

## 设置动作

在「动作映射」点击「添加动作」或已有动作的「设置」。动作由名称、手柄输入、键鼠输出和触发阈值组成。

- 手柄输入可以是按键、扳机或摇杆方向，最多四个。点击「添加组合按键」增加成员，所有成员同时满足阈值才触发。
- 键鼠输出最多四个，可以勾选 Ctrl／Alt／Shift，再选择普通按键、鼠标按钮或滚轮。「添加同时输出」可以增加普通按键或鼠标操作。
- 鼠标支持左键、右键、中键、侧键 1（XBUTTON1）和侧键 2（XBUTTON2）。侧键按住期间保持按下，松开触发输入时释放。
- 滚轮支持上、下、左、右四个方向。一次组合中最多一个滚轮方向，默认每次触发滚动一格。「按住连续滚动」可以设置 20–2000 ms 的整数间隔。
- 扳机与摇杆方向使用动作的「触发阈值」。同一动作中的各成员使用同一个阈值；相反的方向不能放在同一组合里。

例如，手柄「LB + A」可以输出「Ctrl + Shift + K」，「方向键上」可以输出「滚轮向上」，「方向键下」可以输出「Ctrl + 滚轮向下」，「右扩展键 1」可以输出「鼠标侧键 1」。

## 实体录入

点击「录入手柄」后，同时按住组合中的成员，再全部松开完成。后端保留最近一次按下时的完整输入组合，短促组合在界面两次刷新之间结束也可以录入。已按住的设备快照不会自动完成录入。

点击「录入键鼠」后，按住所需键盘与鼠标按钮，全部松开完成。滚轮在滚动时立即完成，因此可按住 Ctrl 再滚动来录入「Ctrl + 滚轮」。表格中的键鼠操作和手柄输入也可以直接点击录入。录入过程中，鼠标侧键不会触发页面前进或后退。

0.9.1 的键盘选键支持 115 个键，覆盖标准主键区、标点、Caps Lock、导航与锁定键、小键盘、左右修饰键和 F13–F24。输出区的「键盘区域」可以切换「主键区」「导航与扩展键」「数字小键盘」。小键盘 Enter、数字和运算键保持独立，不折叠成主键区对应键；修饰键也保留左右区别。按物理键录入，Shift + 数字或标点会分别记录修饰键和原键。

Esc 位于选键区第一排，可点击选择；正在弹窗或表格录入时，点击「映射 Esc」可直接完成 Esc 输出。要配置修饰键 + Esc，可以先在面板选择修饰键再点 Esc，也可以录入时按住修饰键并点击「映射 Esc」。直接按 Esc 继续用于取消，不会意外覆盖原绑定。

输入列的小标签显示「按住」「短按」「长按」「双击」「按下时触发」或「松开时触发」。开启连发的动作额外在动作名旁显示「连发」。这些标签不增加手柄导航焦点。

Esc 或「取消录入」取消操作，窗口失焦也会取消。录入期间暂停光标和全局快捷键配置切换，避免录入默认 F9 或自定义快捷键时切换配置。F12 保留为紧急停止，不能作为动作输出。0.8.0 起，运行中录入只暂停输出，保留当前输入、虚拟设备和隐藏会话；完成后等手柄松开并回中，自动恢复原映射。录入期间禁止保存，文件热更新延后处理。

媒体播放、音量等消费控制页按键尚未接入当前键盘输出，不会显示为可选键；不支持的键仍明确拒绝。

## 模板与批量填键

新建配置时可选「射击与体感」或「动作与探索」。它们预填手柄布局、动作名称与常见键位，创建后会打开批量填写表。已有配置也可以在 Studio 的「游戏配置 → 动作映射 → 批量填键」里选一行，再点「开始连续录入」填写当前层的键位。

- 在空白配置或已有配置的动作映射页点击「悬浮窗录入」，打开可拖动、可调整大小的置顶动作表。也可以在「批量填键」里点击「打开录入悬浮窗」，带上已经填写的键位。
- 点击「新增动作」直接录游戏键位。录完会加一行，名称可以当场修改，手柄输入暂标「待绑定手柄」。可以连续添加多条，再一次写入草稿。
- 在窗口化或无边框全屏的游戏键位页旁，点击已有动作的任意单元格即可修改这一行的游戏键位。键盘在小窗内直接录入，鼠标按键、侧键和滚轮在标记的鼠标录入区操作。
- 点「返回 Studio」或关闭小窗可以继续编辑这份填键表。点「写入配置草稿」将结果交给主窗口，在动作表的输入列为待绑定动作录入手柄，再保存或应用。
- 小窗取得键盘焦点后录入，失焦时暂停。录入期间释放映射输出，保持设备会话。结束后等手柄松开并回中，再恢复录入前的映射。

## 同时触发与释放

更完整的组合优先于被它包含的单键或较短组合。例如同时配置「A → 空格」和「LB + A → Ctrl + K」，在 LB 已按住时再按 A，只输出 Ctrl + K。松开 LB、继续按住 A 时，普通按键动作恢复为按住空格。已发送的单键不会因之后补按组合成员而撤销，建议先按组合中的修饰成员。

滚轮只在新的输入触发沿发送一格；松开组合中的修饰成员不会让仍按住的单键滚轮动作补发一格。重新松开并按下才会再次触发；连续滚动也需要一次新的触发来启动。重连和配置重载后的设备快照不会重放滚轮，调度长间隔不会补发积压的滚动。

多个动作需要同一个输出键时，引擎合并按住状态，直到所有动作都释放才松开该键。组合输出先按下 Ctrl／Alt／Shift，再按普通键或鼠标按钮、发送滚轮；释放时先松开普通键或鼠标按钮，再松开修饰键。停止、配置切换、设备断开、输出失败和退出都执行释放清理。滚轮是瞬时操作，不写入按键保护进程的按住清单。

虚拟 Xbox／DualShock 4 的标准自动映射仍按配置工作，动作组合的优先规则只处理自定义键鼠动作。

## TOML 格式

动作沿用字符串字段，旧单键无需迁移。使用 `+` 分隔组合，输入顺序不影响触发条件。输出最多四个不重复成员，F12 不允许；`repeat_ms` 只可用于含滚轮的输出。

```toml
[[actions]]
name = "组合动作"
input = "left_shoulder+south"
output = "key:CTRL+key:SHIFT+key:K"
threshold = 0.5

[[actions]]
name = "连续向下滚动"
input = "dpad_down"
output = "key:CTRL+wheel:down"
threshold = 0.5
repeat_ms = 100

[[actions]]
name = "鼠标侧键"
input = "right_paddle1"
output = "mouse:x1"
threshold = 0.5
```

方向名称：`wheel:up`、`wheel:down`、`wheel:left`、`wheel:right`。侧键名称：`mouse:x1`、`mouse:x2`。省略 `repeat_ms` 即单次滚动。含这些新值或组合的文件需要 Motion Studio 0.4.0 或后续版本。

## 0.8.0 动作扩展

`trigger` 可选 `down`（默认按住）、`short`、`long`、`double`、`on_press`、`on_release`。`trigger_ms` 默认 250，范围 10–5000；`sustain` 控制长按达到时间后是否保持，默认 true。可选 `turbo_ms` 范围 20–2000，作用于触发方式判断之后；省略即不连发。

输入新增 `left_stick_outer`、`left_stick_inner`、`right_stick_outer`、`right_stick_inner`，可单独绑定或组成组合。同一个摇杆的内外圈不能同时放入组合。`stick_zones` 定义半径和回差；中心死区不属于内圈。可选 `stick_rebound_ms` 开启原版防回弹。

同输入的多种触发方式可以并存；普通按住会立即输出，短按需等松开才能确认。完整设置方法、按住配置层与示例见[配置层与触发说明](action-layers-and-triggers.md)。
