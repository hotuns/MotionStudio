# 光标自动切换（0.9.0）

在「自动切换 → 光标显示状态」开启自动切换，分别选择光标显示、隐藏时的目标配置。「不切换」忽略该状态，「恢复切换前的配置」返回本轮自动切换前使用的配置。需要输入引擎处于运行状态。

「状态确认时间」是光标状态连续保持多久才确认变化，单位毫秒，可输入 **0–5000 的整数**，默认 **250 ms**。旧版本使用固定 250 ms，升级后未设置此字段仍保持该行为。输入完成后按回车或移开焦点自动保存，无需重新启动映射。

- 250 ms 适合过滤菜单开关等短暂光标变化。
- 可以逐步降低数值比较响应；出现短暂状态导致的误切换时增加数值。
- 0 取消额外的稳定确认等待，检测线程仍以约 50 ms 周期检查。线程调度和配置验证、加载也需要时间，因此 0 不表示切换总耗时为零。

确认期间如果状态又改变，重新计算连续保持时间，不累计不连续的片段。修改确认时间、切换目标或开关后重新建立光标基准，不重放修改前尚未执行的切换。开始运行与完成录入时也重新建立基准。只修改确认时间不会丢失“恢复切换前配置”的历史。

该设置属于本机全局设置，保存在 `settings.json` 的 `cursor_debounce_ms`，不写入游戏配置或配置层。空白、小数、负数和大于 5000 的值不能保存。

识别对象是 Windows 系统光标的可见性。游戏自己绘制的光标未必改变系统状态；这样的游戏可以使用可配置快捷键切换。录入动作或切换快捷键期间，自动切换继续遵守现有暂停租约，避免录入过程中改换配置。

同一区域也能设置多条[配置快捷键](controller-shortcuts.md)。每条键盘或手柄快捷键可以选择自己的目标，手柄输入支持摇杆内外圈、触摸和最多四项的组合输入。
