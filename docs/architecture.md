# Motion Studio 架构与恢复策略

## 模块边界

    React 表单 / 手柄示意图
                ↓ Tauri commands / 低频状态
    Tauri Rust：配置库、切换策略、组件管理、引擎监督
                ↓ 本地子进程 stdin/stdout JSON Lines
    motion-engine：FlexInput SDL 事件 → FlexInput 求值器 / Studio 配置适配
                ↓ 键鼠与手柄分别选后端
    键鼠：HIDMaestro（默认）/ SendInput；手柄：原生 ViGEm（默认）/ HIDMaestro
                ↓ 独立输出保护
    HIDMaestro：--hidmaestro-output 辅助进程持有设备、输出锁及释放租约
    兼容模式：--guardian 持有输出锁，失联时释放 SendInput 按键

crates/engine（motion-core）包含配置模型、FlexInput 适配、SDL ABI、时间处理、输出分发和配置存储。crates/host（motion-engine）拥有 SDL 与映射运行状态。src-tauri 负责桌面生命周期。src 是独立前端。

## 输入与性能

SDL 初始化、设备开启和更新在引擎主线程。0.7.0 使用固定 FlexInput 的 SdlBackend，在聚合之前通过原始事件接口交付每条 SDL_EVENT_GAMEPAD_SENSOR_UPDATE，保留主机时间和传感器时间，不对数值相同的样本去重。上游最新值读取仅供传感器看门狗使用，不送入映射积分；高频路径更新 gamepad 状态并清理已翻译的 joystick 队列，不泵窗口消息。

默认用 SDL 事件主机时间积分；可在高级设置选择传感器时钟。零值、倒序时间与超过 50 ms 的采样间隔会重建基准，不把等待时间变成突然的大幅移动。输入事件积压超过 50 ms 时丢弃旧输入并清理状态；新增原始输入队列超限时报告错误并停止。鼠标小数余量跨帧保存，正负方向对称。

0.3.0 增加加速度计独立事件、SDL 到 FlexInput 的六轴坐标换算、每设备方向和六面校准。MotionRuntime 使用 3DOF 求值器计算坐标、姿态和边缘转向，ImuEstimator 提供去重力加速度及倾斜动作量。样本新鲜度按主机时间检查，不混用两个传感器时钟；超过 50 ms 的加速度计数据不用于重力相关输出。高级滤波与曲线复用上游纯算法。体感功能与边界见 motion.md。

鼠标和虚拟右摇杆使用同一个 FlexInput RWS 求值器的两路输出。鼠标按每个样本的时间差积分。虚拟右摇杆按角速度映射偏移，再与实体右摇杆逐轴相加并限制范围。按住暂停、无效时间戳或 50 ms 无新采样时清除体感偏移，保留实体右摇杆位置。配置切换和重连后的按键快照只同步状态，按一下切换体感的模式从关闭开始。

摇杆鼠标约每 4 ms 按经过的时间更新一次。按钮只在边沿发送，虚拟手柄只发送变化后的报告。DualShock 4 在转换为设备的 8 位轴值后再次比较报告。接收队列、日志与状态队列有上限。设备重新扫描只允许在停止后进行，避免枚举接口打断正在运行的体感。

Flick／摇杆瞄准与定角转身按 4 ms 时间推进，和逐条 gyro 积分分开，避免无新 gyro 时重复旧样本。Flick 转角与连续转速分开结算，虚拟摇杆缺少输出余量时保留剩余角度。暂停、断开、重载和调度长间隔取消待输出转角。倾斜动作保持／切换／连发的状态由引擎持有，采样中断时释放。游戏转角测量通过 IPC 开始／结束，测量期间固定基础灵敏度并排除边缘转向等倍率；饱和和时序错误随遥测发布，界面拒绝采用无效结果。

引擎约 15 Hz 发布状态，界面约 6.7 Hz 拉取聚合状态。文件监视每 500 ms 在单独线程读取和解析，校准期间的热更新延后应用。高频输入不经过 WebView 或 Tauri 事件。

性能页面显示实际收到的体感事件频率、处理耗时 P99 和队列等待 P99，不把设备宣称的采样率当成实际输出频率。操作系统调度与设备/接收器的采样质量仍需用真机验证。

## 配置事务

保存前创建候选 Engine 完成格式和语义校验。磁盘存储使用原子替换；当前配置无效时运行态保持最近一份有效配置，错误显示在 UI。

运行时切换先验证候选及必要驱动，再释放旧输出并更换内核。Xbox 360 与 DualShock 4 是独立目标，默认由原生 ViGEm 创建，也可显式选择原生 HIDMaestro。键鼠后端分别保存；兼容模式使用 SendInput 与 ViGEm。类型变化时先将旧目标归零并销毁，再创建所选的新设备。输出保护进程在切换期间持续持有锁。新输出初始化失败后进入暂停状态。切换成功后才更新“恢复切换前配置”的历史。配置按 UUID/固定 ID 寻址，重命名不会使引用失效。

热更新触发后重置时间基准与过滤器；短促物理按键通过递增序号传到前端，避免被 UI 降频刷新漏掉。

0.4.0 的动作输入与输出沿用字符串，以 `+` 表达最多四个成员。手柄组合由 FlexInput 的阈值比较和 AND 求值；严格包含当前输入的组合生效时，通过 NOT／OR 屏蔽较短动作。输出按原子键汇总，避免共享键提前释放。滚轮独立于按住集合，只有真实触发沿才发出脉冲；可选 `repeat_ms` 由引擎时间推进，快照、重连和长调度间隔不重放旧滚动。Windows 输出使用 WHEEL／HWHEEL，侧键使用 XDOWN／XUP；滚轮与侧键分别发送 INPUT。保护进程仅记录和释放五个鼠标按钮及键盘原子键，按普通键在前、修饰键在后的顺序清理。

手柄录入遥测增加 `input_chord`，在真实按键／轴越过阈值时保留完整组合，释放后继续保留供低频界面读取。快照不增加序号，也不会伪造录入事件。界面在候选成员全部松开后提交。键鼠录入由 WebView 处理，不发送系统输入。0.8.0 用 `SetBindingCapture` 输出暂停租约替代重开观察会话：保留 SDL、虚拟设备与隐藏，清空输出，5 秒租约每秒续期；结束或超时后待手柄松开、摇杆回中再恢复原映射。光标和快捷键自动切换同时暂停，热更新延后，保存先拒绝尚未结束的录入。

全局配置切换快捷键保存在本机 settings.json 的 shortcut_key（key、ctrl、alt、shift），旧设置缺少该字段时默认 F9。桌面策略线程约每 50 ms 读取 Windows 主键及精确修饰键状态，仅对新的主键按下边沿执行一次切换；更换绑定、开始运行、结束录入时只建立基准，不重放已按住的按键。只修改按键组合时保留切换前配置历史。录入期间通过 5 秒租约暂停快捷键切换，界面每秒续期，取消、失焦和离开页面时释放；WebView 异常时租约到期自动恢复。F12 的紧急停止继续由输入引擎独立处理。保存、搜索、应用及常见 Windows 保留组合不能用于配置切换。

## JSM 导入与手柄界面

JSM 导入通过 jsm_import.rs 离线生成 Studio 配置。主文件和用户选择的一层静态引用按加载顺序转换。FlexInput JSM Config 解析双段扳机模式和阈值。运行时，同一原生状态机把校准后的模拟行程转成轻拉与全拉输入，供 Studio 动作、配置层和快捷键消费。

协议 4 增加 Navigate 命令。引擎先释放原输出，再使用没有动作、关闭传感器的空白观察配置，不绑定文件监视器，不改变当前游戏配置。按钮和轴生成最多 48 条带序号的导航意图，短促按下在界面轮询之间结束也不会丢失；快照只建立基准。方向键与摇杆合并并带松开阈值，传感器事件不经过导航处理。

界面模式约 33 ms 发布及拉取状态，普通映射保留原频率。WebView 根据导航意图移动焦点、选择选项、调整数值和显示屏幕键盘，不发送系统按键。失焦、断开、录入和恢复连接时清除待执行意图与重复状态，不重放确认。继续游戏需明确启用输出；光标与全局快捷键策略不在界面观察模式中切换游戏配置。

## 设备与重连

完整列出 SDL 的游戏手柄、未映射接口及开启失败信息。只有一个体感接口符合已验证的实体设备条件时，界面才会自动选中。Windows 设备树用于判定来源，因为虚拟 DualShock 4 可以与实体手柄共享 VID/PID。已识别的虚拟设备只出现在诊断和禁选项中。重连匹配所选接口路径。SDL 只提供 XInput 槽号时，断开后返回待机并要求重新选择。

断开时释放按键、中和并销毁虚拟手柄，进入 waiting。重连会重新创建 SDL 会话，以应对第三方接管握手晚于首次枚举的设备。接口路径变化需要用户重新选择。

## 退出与故障

正常停止、F12、断开、应用退出、IPC EOF 都执行输出清理。Dispatcher 记录按下的键，即便 OS 调用失败也保留清理意图；释放一个键失败不会阻止尝试其他键，Drop 再次清理。

兼容模式的输出保护进程在真正发送按键前获得“旧键集合与新键集合的并集”，输出成功后收敛到实际集合。每 400 ms 更新心跳；父引擎退出或 2 秒失去心跳后，用 SendInput 释放记录的键，最多重试三次。它从不按下按键、移动鼠标或创建虚拟手柄。

HIDMaestro 模式复用 FlexInput 固定提交的原生传输、报告编码、驱动部署和设备编排模块。0.6.1 将键鼠发送从采样线程分离，连续鼠标按上游默认 500 Hz 节奏累积并发布，使用原始 HrWaiter 和绝对截止时间，不逐帧等待 ACK，静止时仅发送一次归零转换。确认只保留在发送线程的离散按键、滚轮和释放边界。停止／切换优先取消旧队列，发送中立状态并完成线程释放，虚拟手柄不与键鼠确认共用等待队列。

受限辅助进程负责固定设备的创建和释放；只有主运行循环每 400 ms 异步更新租约，发送线程不会代替采样循环续租。辅助进程检测父进程退出或 2 秒心跳中断后归零并销毁设备，驱动 owner watch 和预注册释放报告覆盖辅助进程被强制终止的情况。设备所有者在全部清理完成前持有输出互斥量；后继映射不能越过旧清理。该后端的安装与版本边界详见 hidmaestro-output.md，复用范围及接口例外见 flexinput-reuse.md。

保护进程持有命名输出互斥量，清理完成前后继引擎不能取得输出控制权。ViGEm 目标随引擎句柄关闭销毁。系统阻止 SendInput 时会报告失败，保护进程不能绕过 Windows 权限。

Tauri 每 250 ms 检查引擎，退出或 6 秒无消息时重启到待机；明确发布的 preparing_output 状态允许最多 120 秒完成 Windows 授权和设备准备，此时尚未发送映射输入。60 秒内最多自动重启三次，然后要求手动恢复。启动应用或恢复进程均不自动开始输出。配置损坏、IPC 长度限制、安装包校验等错误都不会触发静默安装。协议 5 增加本机输出后端选择和实际输出后端状态；观察和界面导航不创建输出设备。

## 上游维护

FlexInput 源码固定提交，manifest 同时保留上游原始哈希和当前移植哈希。无界面入口包含 core、engine、JSM Config、HIDMaestro 原生输出、SDL provider、模块描述和原生虚拟手柄设备。校验覆盖 150 项固定来源与资源。无界面入口、事件 API 和双段扳机接线见 flexinput-reuse.md。

Rust SDL 绑定仅连接当前带飞智修正的 SDL3 DLL。构建禁止第二份静态/源码 SDL，校验 x64 导入库、DLL 哈希和 PE 延迟导入；引擎先加载明确绝对路径，并将模块固定到进程退出，跨会话保留有效导入地址。原生 HID 解析代码虽已编译，当前活动输入统一使用 SDL；其逐样本 provider 接口属于后续工作。

更新上游时在 vendor 内审查差异，重新验证纯内核测试、真实 SDL 合成事件测试、进程测试与性能指标，再更新记录。不能只改哈希来接受未知改动。SDL 补丁与驱动安装包单独固定版本、大小和哈希，不依赖旧 JSM 仓库路径。

## 验证层次

- 纯测试覆盖相同体感值逐条积分、时间间隔保护、平滑、静止抑制、快速转动倍率、切换与暂停、右摇杆回到实体输入，以及两种手柄的报告转换和释放。
- 运行态测试：有效/无效热更新、输出释放、接口固定、父进程 EOF、保护进程重试。
- 进程测试运行实际 motion-engine，使用 SDL 进程内合成设备验证传感器事件到 RWS 右摇杆，并检查文件监视、配置切换、协议退出和空保护租约失联。默认关闭测试子进程中的实体设备后端，真机观察需要显式启用。
- 桌面检查：实际 Tauri 界面新建、编辑、保存、体感表单、驱动只读检测及引擎恢复。
- 真机验收：长期游戏手感、物理拔插/无线失联、休眠恢复、虚拟手柄在目标游戏的识别，需要用户在对应游戏与设备上测试。

## 反馈、触点与体感录入

反馈每 8 ms 从原生 VirtualDevice::poll_outputs 读取，命令序号与值在同一快照内。Studio 会话适配器限制强度、在暂停后等待新命令，并通过同一个所选 SDL OpenPad 的原生 DeviceBackend::send 发送；原生 LedOut 继续处理颜色合并与限频。停止、录入、校准、切换和断线清除已接管反馈，观察模式不接管马达。虚拟输出仍按原生设备编码，不引入第二份实体句柄。

SDL 事件模式在上游关闭全部手柄事件后明确启用触点按下、移动与抬起订阅，保留 FIFO、主机时间与原始坐标。原生 route_touchpad / trackpad.rs 计算指针、双指滚动、轻点、拖动和双板组合；Studio 仅转换配置并管理基线与输出合并。touch1／touch2 同时进入既有组合、体感和按住层输入，录入恢复需要触点也松开。详见 [游戏反馈与原生触摸板](peripheral-feedback-and-touch.md)。

0.11.1 在体感开启与暂停输入旁复用动作编辑器的录入租约。读取引擎已经发布的原始按下、接触及释放状态；只将一个输入写入当前基础配置或编辑层，物理触摸板按下优先于同板的接触。录入与输出恢复均等待控制归零。开发用 `--self-test` 仍由进程测试运行，桌面应用不提供自检入口。

## 映射隐藏会话（0.8.0）

引擎在打开所选 SDL 输入前，通过复用的 FlexInput 原生 HidHide 客户端登记实际引擎读取权限并持有实体隐藏会话。独立普通权限进程维护心跳与原子恢复日志；设备树查询复用原有 CfgMgr32 API。输出创建返回精确虚拟节点，核验其及祖先未被隐藏后才开始分发。切换、校准和等待重连保留隐藏，完整停止先释放输出再仅恢复会话新增规则。恢复失败保留记录，下次启动及手动恢复重试。详见 [生命周期说明](hidhide-lifecycle.md)。

## 动作与按住层（0.8.0）

`Action` 增加触发方式、时间、长按保持及可选连发周期，默认仍是立即按住。直接调用 FlexInput `PressGate`，组合与优先级仍由原图求值。内外圈调用 `core::area::AreaLayout`；防回弹调用原 `StickRebound`。轴事件和 4 ms 时间推进都会更新回弹到期状态，不需要新轴值才恢复。

根配置保留基础层与最多八个稀疏层；运行引擎持有合并后的平面配置。启用输入以物理状态和基础区域判定，模拟输入有释放回差。`Engine::apply_layer` 保留采样时钟、未修改动作状态和滤波器，只在对应配置变化时重建局部图。Dispatcher 对目标按住集合做差异发送，切层不重开 SDL 或虚拟输出。所有可能叠加组合在保存前校验。

## 本地化与切换提示（0.8.0）

语言偏好是本机 `Settings.language`（`zh-CN`／`en`）。React 外部状态触发重绘；自动 JSX 入口在创建原生文本与无障碍属性时调用目录翻译，不修改 DOM、受控输入值、事件处理器或配置 ID。动态字符串使用参数模板；用户名称与文本显式标为 `translate="no"`。切换语言不重挂编辑器、不清空草稿。`npm run verify:i18n` 核对拆分目录、合并目录、参数占位符及生产 TSX/Rust 文案覆盖。

原生 GDI 浮层在独立线程持有分层顶置窗口，透明命中、不激活、不抢焦点。空闲用条件变量等待，显示期间才推进淡出；新通知替换旧通知。成功配置切换之后才排入提示，本机设置控制开关、四角位置、时长和语言。它是普通系统窗口，不注入游戏进程；独占全屏不保证显示。

## 编辑与光标策略适配（0.9.0）

本机设置增加 `cursor_debounce_ms`，默认 250、范围 0–5000。原 `CursorEdges` 状态机增加可传入确认时间的入口；零值在首次观察到变化时确认，起始样本仍只建立基准。策略线程保持约 50 ms 检查周期，光标开关、确认时间或目标改变时清空候选和待执行边沿。取得操作锁后重新核对设置与录入版本，防止旧边沿越过刚开始的录入。只改确认时间保留切换恢复历史。

顶部 `LayerToolbar` 共用 `App` 的稀疏层编辑状态，位于当前配置选择器右侧。层管理用独立窗口复用原 `LayerPanel`；选择编辑层只改变前端写入上下文，不发送激活层或重新启动命令。切换配置或删除选中层后清除失效上下文。新 `ActionEditor` 复用既有触发字段、组合编码、输出暂停录入和草稿保存入口，提供按钮／键盘直接选择，未新增另一套映射状态机。

控制器 LB／RB 区域切换使用当前焦点最近的 `data-pad-zone`，使嵌套窗口中的输入、输出和底部按钮可达。原生 `optgroup` 的 label 加入 JSX 翻译属性集合；用户配置名、层名、动作名和受控输入值仍保留原始内容。本轮没有修改 FlexInput vendor、驱动和 SDL。

## 键盘目录与录入（0.9.1）

`src/keyboard-keys.json` 是前后端共用的 115 键目录。React 使用名称、显示标签、DOM 物理 code 与区域；Rust 用同一份嵌入目录校验配置、判定修饰键、查询 Windows VK 和扩展标志。Caps Lock、主键区与小键盘 Enter、左右修饰键都保留独立身份。全局配置切换快捷键继续使用自己的可用范围与保留组合规则。

HID 普通键调用 `flexinput-virtual::keyboard` 暴露的原始 FlexInput 查询，目录只适配现有标识。上游缺少的小键盘、锁定键、菜单键和 F21–F24 明确保存标准 USB 用途码，并对照现有 SDL 绑定的扫描码枚举核验；修饰键使用原键盘字节的八个位。兼容输出通常发送扫描码，Pause 与 Print Screen 使用系统虚拟键处理特殊序列。事件构造与真正发送分开，自动检查只构造和核对事件，不发送系统输入。

录入优先读取 `KeyboardEvent.code`，不会把 Shift + 数字误当成标点或把 Num Lock 关闭时的小键盘误当成导航键。修饰键同步保留已识别的左右身份。Esc 继续取消录入，弹窗和列表快捷录入提供同一个「映射 Esc」提交入口；四成员上限、录入租约和暂停／恢复输出流程保持一致。动作触发标签使用原有六种触发名称，不额外生成导航焦点。
