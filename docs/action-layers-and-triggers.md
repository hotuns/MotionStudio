# 配置层、触发方式与运行中录入

## 配置层

配置层属于当前游戏配置，适合“按住 LB 开镜时降低体感灵敏度”“按住某键把一组动作变成另一组动作”等用途。它采用 Steam Input action set layer 的继承思路，不是专门的开镜功能。默认按住启用输入时叠加覆盖，松开恢复；也可在「层启用方式」选择「按一下开启，再按一下关闭」；既有全局快捷键的整份配置切换仍独立工作。

操作示例：

1. 在顶部当前配置右侧的「编辑层」选择「基础层」。在「游戏配置 → 动作映射」把左肩键映射到鼠标右键，在「体感」设置平时的灵敏度。
2. 点击「编辑层」旁的齿轮，打开「管理配置层」，点击「添加配置层」，命名为“精确瞄准”，启用输入选择 LB／左肩键。点击「完成」返回编辑。
3. 保持顶栏正在编辑此层，进入「游戏配置 → 体感」，把灵敏度调低。基础层的值保持原样。各页签使用同一编辑层，管理窗口内可以调整优先级、恢复继承或删除层。
4. 保存并启用映射。按住 LB 时，鼠标右键保持按下，同时使用此层的灵敏度；松开后回到基础值。

修改层时只存储实际改变的字段。未覆盖的体感、摇杆参数及动作继续继承基础层；以后修改基础层，这些项目也会跟随。编辑器选择某层只是编辑覆盖项，不会强制让运行中的层生效。足够宽的顶栏在映射当前配置时显示「运行：」指示，管理窗口也显示实际运行层。切换游戏配置时重置为新配置的基础层。

配置参数旁显示「继承基础层」或「本层覆盖」。点击参数旁的「恢复继承」会删除这项覆盖，而不是复制当前基础值，因此以后修改基础层仍能继续继承。开启方式、开启按键与暂停按键作为一组恢复，控制方式与其关联的输出、边缘转向也作为一组恢复，避免留下不一致的组合。中心偏移、握持角度和圆周校准等数组按整组恢复。所有恢复操作先写入草稿，沿用保存和应用流程。

管理窗口的「完成」与动作窗口的「完成」会更新当前草稿；点击工作台底部「保存配置」才持久保存。编辑当前运行配置时保存会应用修改；需要改用正在编辑的其他配置时，点击「应用修改」。

- 最多 8 个配置层，启用输入支持最多 4 个成员的组合。扳机与摇杆方向可设置触发阈值和释放回差。
- 多层同时启用时按列表顺序叠加，后面的优先。可用提高／降低优先级调整。保存时校验全部可能的叠加组合，避免只在某种组合下出现无效参数。
- 层可以覆盖体感、摇杆鼠标、死区、摇杆区域和防回弹，并添加、替换或禁用键鼠动作。层的启用依据实体按键、轴和基础层的摇杆区域；层修改区域或滤波不会反过来改变自己的启用条件。
- 此层添加某个手柄输入的动作，会替换较低层中相同输入的全部触发方式；其余输入继续继承。组合成员顺序不影响匹配。例如 `LB+A` 和 `A+LB` 是同一输入。
- 删除覆盖动作即恢复继承。需要禁用该输入的继承键鼠动作时，用「在此层禁用」。虚拟手柄使用单独的布局覆盖，可在当前层的动作表里编辑或删除对应行，在配置层设置中清除整套覆盖以恢复继承。
- 「恢复继承：体感」等按钮删除对应类别的覆盖。可先修改基础层再切回此层确认继承效果。
- 输出设备属于基础层。操作层不会创建、销毁或切换虚拟手柄，不会改变 HidHide 会话。

切层保留输入会话、采样时钟、未修改动作的长按进度与滤波状态，并由输出分发器比较按住集合。示例中的鼠标右键不会因灵敏度变化先松开再按下。新覆盖的边沿动作不会因为切层时已按住输入而补触发滚轮、双击等操作；松开再按才触发。

可读取并分享的完整示例在 `examples/hold-layer.toml`。参考 [Steam Input action set layers](https://partner.steamgames.com/doc/features/steam_controller/action_set_layers?l=english)。

## 层关闭、覆盖预览与输出保持

管理配置层时可选择「关闭此层」和「返回基础层」输入，均可使用右侧的「监听手柄输入」。返回基础层会关闭全部操作层；仍按住的层启用输入需先松开再按，避免立即重新打开。关闭或返回输入本身已设置的普通动作仍会执行。

「层覆盖预览」列出当前层会替换、禁用的低优先级动作，并提示哪些当前动作会被更高层覆盖。这些覆盖只在相应层同时启用时生效。同一输入的全部触发方式一起替换；虚拟手柄映射列表按整组覆盖。

动作编辑器的「再次触发才停止输出」适用于键鼠按键与虚拟手柄数字按钮：第一次按指定触发方式启动输出，松开仍保持，再次触发停止。与长按、双击、组合键及连发共用现有判定；保持期间连发由输出时钟驱动。模拟摇杆和扳机行程仍直接跟随输入。滚轮默认只发送一次；启用连续滚动间隔后才在保持期间持续滚动。组合键优先触发会取消被占用单键的保持状态。

停止映射、断连、输入重同步、切换配置或开始录入会清除保持状态；重连快照不会触发开关，已按住的输入需先松开再按。修改操作层时，未改变的动作保留状态，被移除或修改的动作释放输出。F12 和原有故障释放路径继续生效。

动作映射页的「实时映射状态」展示当前已保存、正在输出的配置：等待组合、长按、双击、等待释放、被其他触发占用、正在输出或保持中。它随状态面板刷新，短暂判定可能发生在两次刷新之间，不是逐事件日志；被层移除的动作请查看覆盖预览。

## 动作编辑器

「游戏配置 → 动作映射 → 添加动作」打开双栏编辑器，交互参考 JSM Studio 的按键快速选择与完整编辑方式：

- 左侧点击大录入区域读取手柄输入，或直接点击常用手柄按钮；展开「完整输入与组合设置」可使用全部输入选项。模拟扳机或摇杆方向会显示触发阈值。
- 六种触发方式直接点击选择，长按、双击和边沿触发按所需设置时间；同一方式再次点击不会重置时间。可选按住连发。
- 右侧点击大录入区域读取键鼠，或使用键盘布局、「鼠标」「滚轮」分类选择。鼠标包含左右中键与两个侧键，滚轮包含四个方向及连续滚动间隔。
- Ctrl／Alt／Shift 可以独立叠加；需要多个普通键或鼠标操作时开启「组合输出」。输入组合和输出组合各最多四个成员，已选成员以标签显示，可逐项移除。滚轮组合最多包含一个方向，选择另一方向会替换原方向。
- 新动作的输出从空白开始，必须明确选择后才能完成；只选择 Ctrl 等修饰键不会自动附加空格。
- 「完整输出与组合设置」保留全部按键与组合选项。小窗口通过内容区滚动操作，底部取消／完成始终可达；手柄 LB／RB 可切换输入、输出与底部操作区域。

窗口显示正在编辑的层，动作会保存到该层的覆盖中。切换编辑层不会激活对应运行层。

## 六种动作触发方式

在键鼠动作或虚拟手柄的数字映射设置中选择「触发方式」。组合输入也能使用这些方式，计时从整个组合成立时开始。虚拟摇杆和扳机行程的模拟量直连保持连续输出；扳机轻拉、全拉和摇杆方向作为数字输入时可使用完整触发设置。

| 方式 | 行为 | 适合的用途 |
|---|---|---|
| 按住 | 单独绑定时立即按下，松开时释放。共用输入时按识别结果补发 | 移动、开火、开镜、奔跑 |
| 短按 | 在最长时间内松开后确认，并输出这次按住的时长 | 与同输入的长按区分 |
| 长按 | 达到设定时间时生效；可保持到松开，或仅触发一次短脉冲 | 长按交互、备用动作 |
| 双击 | 第一次按下后的时间窗内，再次按下时生效；保持到第二次松开 | 双击切换或快捷动作 |
| 按下时触发 | 单独绑定时按下即输出一次。共用输入时按识别结果延迟输出，持续设定时间 | 固定时长点按 |
| 松开时触发 | 松开时输出一次，持续设定时间；同输入的短按、长按或双击可优先占用 | 释放后确认 |

时间范围为 10–5000 ms。例如给 X 绑定「按住 → R」与「长按 300 ms → E」，300 ms 前松开只补发 R，达到 300 ms 只触发 E。补发的按住动作沿用本次按住时长，最短 10 ms。「短按」还受自己的最长时间限制。同一组合的成员顺序无关，模拟轴须使用相同的触发阈值。计时沿用输入事件的时间戳，输出刷新频率不决定触发窗口。

同一输入配置多种方式时，键鼠和虚拟手柄数字动作共同参与判断：

- 普通动作与短按共用时，短按时间内松开由短按生效；超过短按时间才允许普通动作继续判断。
- 配有双击时，单次轻按需要等待从第一次按下开始计算的双击窗口结束。第二次按下被识别为双击后，取消待触发的普通、短按和松开动作。编辑器显示当前需要等待的窗口。
- 长按和双击共用时，先识别成功的方式占用本次输入，直到松开。双击第二次持续按住不会再转成长按。
- 多条相同触发方式仍可同时输出；多条长按使用最早阈值作普通动作的分界，短按和双击分别使用最晚截止时间。各行仍需满足自己的时间条件。
- 开启某行的「允许同时触发」后，该行独立识别自己的触发方式，不参与其他行的竞争，也不让其他行等待它。例如普通动作或长按动作任一行开启后，普通动作可立即输出，长按动作达到时间时一起生效。默认关闭。

「按住连发」使用单独的 20–2000 ms 周期，先判断触发方式，再连发；因此长按动作要达到长按时间后才开始连发。滚轮还有独立的「按住连续滚动」，用于控制每格滚动间隔，通常选择其中一种重复方式即可。

双击识别、长按输出、脉冲与连发复用固定 FlexInput 的处理函数；时间戳适配层负责同一输入的竞争和延迟补发，详见[复用记录](flexinput-reuse.md)。双击的时间窗只限制两次按下之间的识别，第二次已按住后不会因时间窗到期突然释放。参考 [Steam Input activators](https://partner.steamgames.com/doc/features/steam_controller/activators?l=english&language=english)。

## 手柄映射详图

在「游戏配置 → 动作映射 → 手柄映射概览」点击「查看具体映射」，打开大视图。每条映射直接显示动作名称、完整手柄输入、输出按键及触发方式，例如「换弹 · X → R · 长按 300 ms」。同一按键的多个动作分别列出，组合输入会出现在每个成员所在的控件分组中。虚拟手柄映射、体感动作、定角转身以及已开启的摇杆鼠标、Flick Stick 和体感瞄准也会显示。

详图读取当前草稿。编辑配置层时，它显示基础层与当前编辑层叠加的结果，标明「继承基础层」或「本层配置」，隐藏已被该层替换或禁用的基础动作；其他配置层不会加入此预览。它不是运行中全部生效层的状态视图，实时状态仍在「实时映射状态」中查看。

点击手柄控件可以定位映射，点击当前层的动作可以打开编辑器，点击继承动作可以前往基础层。摇杆和体感设置条目会前往对应设置页。浏览详图不会保存草稿、开始录入或暂停映射；长动作名称自动换行，窗口较窄时分组改为纵向排列。

## 摇杆八向映射

在「游戏配置 → 摇杆 → 摇杆方向映射」中，左右摇杆可分别选择「八向重叠（适合 WASD）」或「按轴阈值」。将上、左、下、右分别绑定 W、A、S、D 后，八向模式会在斜推时输出相邻两键，如 W+D。左右摇杆的「斜向重叠角度」可分别设置为 0–90°，并通过区域预览查看范围：调大更容易进入双键斜向，调小更容易保持单方向。0° 只输出四个单方向，恰好位于斜线时选择水平方向；90° 时除正方向外均输出相邻两键。

默认保持 JSM `NO_MOUSE` 的原生判定（约 36.87°），旧配置和 JSM 导入不会被自动改成新的角度。点击「恢复默认角度」回到原生规则。自定义值随游戏配置保存，可由配置层覆盖；调整宽度同切换布局一样，会取消受影响的待触发手势。按轴阈值模式不使用重叠角度。

两种布局均先经过输入校准和死区。八向模式的动作阈值判断摇杆整体幅度，按轴模式判断对应轴的幅度。现有 Studio 配置默认按轴阈值；导入 JSM 方向绑定时选用八向，并将动作阈值设为零，使其在输入死区之外立即响应。摇杆外圈仍可独立绑定 Shift。切换布局的配置层会取消受影响的待触发手势，避免用旧方向状态继续计时。

## 摇杆外圈与内圈

「游戏配置 → 摇杆」可调左右摇杆外圈阈值及回差。默认外圈半径 0.85、回差 0.05，推到外圈触发，回到约 0.80 内释放，减少边界附近反复开关。

要让左摇杆推到外圈时触发奔跑，在「动作映射」添加动作，将手柄输入选为「左摇杆外圈」，键盘输出选为 Shift。内圈和外圈按半径判定，斜推也生效。内圈排除中心死区，摇杆回中不会误触发。

防回弹复用 FlexInput `StickRebound`，默认关闭，可选 10–150 ms。用于抑制摇杆快速回中后短暂越过另一侧造成的误方向；开启初始值为 40 ms。过滤到期即使轴数值没有再次变化，也会恢复正常判断。它会影响摇杆手感，先用默认关闭状态比较，再决定是否启用。

## 映射运行中录入

运行中点击「录入手柄」或「录入键鼠」时，只暂停映射输出，保留 SDL 输入、输出设备及 HidHide 会话。已按住的输出先释放，录入的按键不会继续发送给游戏；光标和全局快捷键自动切换同时暂停。

完成、取消、失焦或录入租约超时后，界面会提示松开手柄按键、松开扳机并让摇杆回中，再自动恢复原映射。不会因为一次录入进入“断开再连接”。5 秒租约由界面每秒续期，WebView 中断也能退出录入。F12 仍会完整停止映射。

录入时禁止保存，避免尚未完成的录入与热更新交错；外部配置更新延后应用。恢复后先保存修改，才把新绑定应用到运行中的配置。

## Interface language

Use the **Interface language** selector in the lower-left sidebar, beside the theme button, and choose **English** or **简体中文**. It remains visible while the navigation scrolls. The change applies immediately, preserves unsaved edits and is saved locally. Profile names, action names, layer names, binding identifiers and exported TOML are user data and remain unchanged. Controller navigation, search, accessibility labels and native profile-switch notifications follow the selected language.

In English, use **Edit layer** beside the current profile in the top bar. Its settings button opens **Manage action layers**. Add a hold layer, set its activation input, then edit gyro or stick settings while that layer is selected. Unchanged fields inherit the base profile. Selecting an editing layer does not activate it in the running mapping. Use **Activation type** in action settings for hold, short press, long press, double press, press-edge and release-edge actions. The editor also offers direct controller buttons, keyboard keys, mouse and scroll categories, removable chord members and full settings.

Application messages are translated. Operating-system errors, third-party diagnostics and text written by users may retain their original language.


## 组合等待时间

键鼠动作和虚拟手柄数字映射在选择两个以上输入后，显示「组合等待时间」。默认 **80 ms**，范围 **0–500 ms**；已有配置未写入 `chord_wait_ms` 时同样使用 80 ms。单键映射本身不增加固定延迟，只有被组合包含的映射才等待。多条相同输入、相同阈值的组合共用最长等待时间。

例如 LT → 技能 1、RT → 技能 2、LT + RT → 大招：在窗口内完成组合只输出大招，取消两个单键的待输出动作，直到全部成员松开。超过窗口则按单键输出，本次按压不能再转成组合；全部松开后重新判断。单独快速点按不会因短于窗口而被吞掉，沿用 FlexInput 的补发处理。模拟扳机从开始扣动时计时，组合成立仍要求全部输入达到该组合的触发阈值；扳机行程直通输出与 DS4 数字扳机位一起暂缓，快速单扣补发使用暂缓期间保留的行程。

设为 **0 ms** 时不等待，组合成立前已经发出的单键无法撤回。组合成立后的单键屏蔽仍保持到所有成员松开。「允许同时触发」只控制同一输入的短按、长按、双击竞争，不绕过组合占用。短按、长按、双击仍按原始输入时间判断，组合等待仅暂缓或取消其输出。
