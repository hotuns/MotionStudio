验证开始：2026-11-08；报告生成：2026-11-09 00:22:50（Asia/Shanghai），Windows x64。FlexInput 固定来源：0.16.9 / c69f53ad3bca4ed34ef5f2d63509addaa7c767be。

## 本版接入

- 游戏反馈：原生 VirtualXInput、VirtualDS4、HidMaestroDevice 的 poll_outputs 经原生 DeviceBackend::send 回传到同一个所选 SDL 句柄。支持震动与灯光分别启停、0–2× 震动强度、配置层覆盖、原生灯光合并与最终提交。Studio 提供配置和生命周期基线，没有替换报告编码、反馈解码或灯光调度。
- 触点：原始 SDL 按下／移动／抬起 FIFO 保留主机时间戳和坐标；原生 eval_graph_tick / route_touchpad 执行原始 trackpad.rs。支持单指移动、双指滚动、轻点左右键、物理按下拖动及双板左右分工／中键组合。指针默认关闭，旧配置不自动产生鼠标移动。
- 接触触发：touch1／touch2 可单独或组成组合输入，使用已有动作触发、体感启停／暂停和按住配置层。接触输入不要求开启触摸板鼠标；没有混入尚未接通触点的全局配置快捷键路径。
- 离线自检：设置与组件内新增中英文入口。校验引擎与 SDL 后启动独立隐藏进程，清除继承 SDL 提示并关闭所有物理后端；检查实际 DLL 的体感样本、触点事件和原生手势，不创建系统虚拟手柄或发送桌面输入。异常结果不能显示成功，超时结束测试进程并允许重试，当前映射不受影响。

## 生命周期核查

- 反馈命令序号与被读取的反馈值属于同一原子快照；暂停期间的反馈只更新基线。同电平的新命令可以恢复，旧命令不能继续震动。持续震动按 250 ms 续期原生 1 秒租约，反馈检查周期为 8 ms。
- 停止、录入、断线、校准和配置切换释放已接管的反馈；取消排队的灯光颜色。新建观察会话不会发送清理马达指令。界面电平表示软件状态，不是实际马达动作确认。
- 触摸板启用／切换／重连对已接触手指等待全部抬起；录入恢复还等待触点松开。无效坐标与长断流清理手势状态，触摸按键输出与普通动作按键合并。拒绝的配置层变更不重置现有拖动，未修改的触摸设置保留手势状态。
