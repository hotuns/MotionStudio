# Motion Studio

Motion Studio 是 JSM Studio 的后继项目，面向 Windows x64。它沿用 Studio 的操作方式，使用 FlexInput 处理手柄输入与体感，并将游戏配置保存为可分享的 TOML。

Motion Studio is the successor to JSM Studio. It is a Windows controller mapper and gyro-aiming tool with a Studio interface and a FlexInput core. The app supports 简体中文 and English.

## 下载与迁移

在 [GitHub Releases](https://github.com/hotuns/MotionStudio/releases) 下载 Windows 预览版的安装包或便携版。发行页附 SHA-256 校验值和已知限制。

从 [JSM Studio](https://github.com/hotuns/JSM_Studio) 迁移时，在「游戏配置」或「配置库」选择「导入 JSM 配置」，打开旧版导出的 TXT，核对转换报告，再创建新的 Studio 配置。两款应用各自保存本机数据，试用时请一次只启动一个映射会话。复杂的轻按／长按绑定和部分高级 JSM 命令需要按报告核验或补配。详见 [JSM 导入与兼容范围](docs/jsm-import.md)。

## 功能概览

「游戏配置」包含动作映射、摇杆、扳机、触控和体感五个页签，同一份 TOML 覆盖这五页。手柄静止与六面校准位于「设备与输入」，游戏内转角校准位于「游戏配置 → 体感」。

0.11.0 补齐游戏震动／灯光回传，以及原生触摸板鼠标、双指滚动、轻点、拖动与双板组合。新增触摸接触输入，可用于体感启停、动作和按住配置层；旧配置默认关闭触摸板鼠标。设置和原生复用边界见[游戏反馈与触摸板](docs/peripheral-feedback-and-touch.md)。

在「游戏配置 → 体感」的简易模式中，可以选择鼠标或右摇杆瞄准、启用方式、灵敏度和防抖预设。切到进阶模式可以调整其余体感参数，包括触摸板按下或手指接触来启用和暂停体感。连接手柄后可以直接录入，松开后写入当前草稿。

面向 Windows 的体感与手柄映射桌面工具。Tauri 2 + React 界面，独立 Rust 输入进程，SDL3 传感器事件输入。

界面沿用 JSM Studio 的工作台、导航、浅色和深色主题。顶部选择配置、启用或暂停输出。底部保存、撤销和应用修改。输入由独立 Rust 引擎处理，游戏配置保存为 Motion Studio TOML。

0.10.0 新增 Rhai 自定义体感处理链：三个接入阶段、独立状态与参数、排序启停、源码编辑／导入、真实运行时合成预览、故障旁路和运行诊断。详见[脚本接口与使用说明](docs/custom-motion-filters.md)。语言切换已移到左下角，与主题按钮并排；导航滚动时保持可见，并保留未保存编辑。

「自动切换」新增手柄单键／最多四键组合快捷键，与键盘快捷键共用目标，按一次切换、再按一次返回。录入暂停输出并等待松开，保持连接与隐藏会话，详见[手柄配置快捷键](docs/controller-shortcuts.md)。摇杆输入完整经过 FlexInput 原生校准、左右死区、防回弹与数字扳机处理，Flick／配套瞄准、普通鼠标和虚拟摇杆共用结果，详见[摇杆输入与死区](docs/stick-aim-deadzones.md)。

虚拟手柄直接使用 FlexInput 原生设备实现；键鼠与手柄后端可分别选择，默认 HIDMaestro 键鼠配合 ViGEm Xbox／DS4。「检查虚拟手柄」显示实际创建状态和 XInput 槽位。复用清单和未接入边界见[原生输入／输出核查](docs/native-input-output.md)。

0.9.1 在动作名旁用小标签显示触发方式及连发，并补齐键盘输出：共用 115 键清单覆盖 Caps Lock、Esc、标点、导航键、左右修饰键、数字小键盘和扩展功能键（F12 保留停止）。Esc 在选键区第一排；录入时可点「映射 Esc」，直接按 Esc 仍取消。HID 使用 FlexInput 原始键码查询，前后端选择、录入、保存校验及兼容输出共用清单。详见[键鼠映射](docs/bindings.md)与 [0.9.1 验证记录](docs/verification-0.9.1.md)。

0.9.0 将光标状态确认时间开放为 0–5000 ms，默认保留 250 ms；配置层选择移到顶部当前配置右侧，在各个调校页面共用。动作编辑器改为双栏工作台，支持直接选择手柄输入、六种触发方式、键盘布局、鼠标与滚轮分类，以及可逐项移除的组合键。完整选项和运行中录入继续保留。详见 [0.9.0 验证记录](docs/verification-0.9.0.md)。

0.8.2 修复自动隐藏将实体 USB 手柄的 ACPI 电脑根节点误判为虚拟设备的问题，同时从硬件 ID 和兼容 ID 识别 HID 功能。复合手柄优先隐藏具体 XUSB 功能及游戏 HID，保留共享的键鼠兄弟接口；真正的虚拟设备仍禁止作为目标。详见 [0.8.2 验证记录](docs/verification-0.8.2.md)。

0.8.1 修复手柄可视化的按键标识不一致：设备输入、游戏配置预览和工作台统一使用运行态按键名称。ABXY、肩键、方向键、功能键、摇杆按下和已报告扩展键可正常显示按下／松开，预览点击可定位绑定动作；扳机高亮和摇杆区域绑定指示同时补齐。详见 [0.8.1 验证记录](docs/verification-0.8.1.md)。

项目定位为 **Studio 交互层 + FlexInput 内核**：底层已有能力优先复用，Studio 维护配置转换和生命周期适配。0.8.0 新增按住配置层、六种动作触发、摇杆内外圈、防回弹、运行中无断连录入、映射隐藏生命周期、配置切换浮层与中英文界面。触发状态机、区域判断、防回弹和原生 HidHide 控制均复用固定 FlexInput 源码。连续鼠标沿用独立发送节奏，并直接复用高精度计时器和原始曲线／滤波模块。详见[复用边界](docs/flexinput-reuse.md)。已安装的 HIDMaestro 驱动不需要重新安装。

## 已实现

- 游戏配置：统一管理动作映射、摇杆、扳机、触控和体感。手柄按键、扳机和摇杆方向可以组成最多四个输入的组合，映射到键盘、键鼠组合、鼠标五键或四向滚轮；支持实体录入、自定义动作、配置重命名。
- JSM 导入转换为可编辑的 Studio 配置，支持所选关联文件和逐行转换报告。左右扳机的轻拉、全拉和快拉模式复用 FlexInput JSM 状态机。
- 配置库支持浏览 GitHub 社区配置、输入短码和复制离线配置码。预览动作与体感用法后可保存为本地副本。[社区投稿说明](community-configs)
- 手柄界面操作：方向与左摇杆移动焦点、A 确认、B 返回、LB／RB 切区域、右摇杆滚动、Y 保存，包含选项窗口、数值调整、屏幕键盘和应用内文件选择器。
- 组合输出支持 Ctrl／Alt／Shift、多个普通按键与鼠标操作；滚轮每次触发滚动一格，也可开启按住连续滚动并设置间隔。组合动作生效时优先于其包含的单键动作。
- 动作支持按住、短按、长按、双击、按下时触发与松开时触发，并可设置连发。左右摇杆内外圈可映射动作，并可启用防回弹。
- 通用按住配置层：只覆盖需要改变的体感、摇杆与动作；未覆盖项继承基础层。支持组合启用、模拟输入回差、多层优先级与禁用继承动作，切层保留采样时钟和共同按住键，不重建虚拟手柄。
- 映射运行中录入只暂停输出，保留输入、虚拟设备和隐藏会话；完成后等待手柄回中并松开，再自动恢复。
- 体感瞄准可输出鼠标位移或虚拟右摇杆。支持常开、按住开启、按一下切换，以及按住暂停。可调灵敏度、纵向比例、反转、时间平滑、静止抑制和快速转动倍率。
- 体感高级控制：本地俯仰／偏航或横滚、玩家／世界坐标、握持补偿、姿态摇杆与归零、边缘持续转向、体感旋转摇杆与接管、Flick Stick、定角转身和 Trackball 惯性体感。
- 稳定与曲线：EMA、速度衰减平滑、One Euro、角度吸附、减速刹车、低速截止与恢复、实测噪声抑制；七类加速响应含可编辑多点曲线。
- 体感动作：角速度、倾斜与去重力加速度绑定键鼠或虚拟手柄，支持保持、切换、连发和动作曲线。设备静止噪声测量、加速度六面校准、安装方向修正与游戏转角测量。
- 摇杆鼠标：持续按住摇杆即可持续移动；速度、死区和响应指数可调。
- 虚拟 Xbox 360 和 DualShock 4（PS4）输出。标准按钮、方向键、摇杆和扳机自动映射，也可以添加键鼠动作。
- 六种配置起点涵盖键鼠与体感、仅体感、虚拟手柄、手柄与体感、光标操作和空白。
- 配置热更新：界面保存后应用，外部编辑当前 TOML 也会重新验证并加载。无效修改不会替换正在运行的配置。
- 配置切换：手动启用；光标显示、隐藏分别选择目标，也可不切换或恢复切换前配置；光标状态确认时间可设为 0–5000 ms，默认 250 ms。可录入全局切换快捷键，默认 F9，支持 Ctrl／Alt／Shift 组合，再按一次返回。
- 配置切换提示：系统原生浮层，支持四角位置、显示时长和预览，不抢焦点或拦截鼠标。适用于窗口／无边框全屏，真正独占全屏下的显示由游戏和系统决定。
- 自动重连：固定设备接口路径，断开释放输出，重新接入相同接口后重开。不会因名称相似改用另一个手柄或 XInput 接口。
- 组件管理：HIDMaestro 原生 HID 输出、HidHide 和 ViGEmBus 检测、内置驱动部署、引擎读取权限和本应用规则恢复。
- 异常恢复：F12 停止、独立按键释放保护进程、引擎崩溃/无响应恢复待机、有效配置备份、诊断导出。
- 简体中文与 English 界面可即时切换，保留未保存编辑；手柄导航、搜索、无障碍标签与原生切换提示随语言变化，用户配置名和按键标识保持原值。

## 开发运行

环境：Windows x64、MSVC Rust 工具链、Node.js 22.12+、Microsoft C++ Build Tools、WebView2 Runtime。

在本项目目录运行：

    npm ci
    npm run dev

网页开发端口为 1435。必须通过 Tauri 桌面程序使用输入设备；单独打开网页不会启动映射。

    npm test
    npm run test:ipc
    npm run verify:resources
    npm run verify:i18n
    cargo clippy -p motion-core -p motion-engine -p motion-studio --no-deps -- -D warnings
    npm run build

构建生成 target/release/bundle/nsis 下的安装包。安装包包含输入引擎、修复版 SDL、内嵌 HIDMaestro 驱动包及 HidHide／ViGEmBus 的原版安装程序。主界面和输入引擎使用普通权限；点击 HIDMaestro 安装或首次启用 HID 输出时，Windows 会为输出辅助进程请求管理员授权。

## 第一次使用

1. 在「设备与输入」选择接口。需要体感时，选择标有「体感可用」的接口。点击「开始观察输入」检查按键和采样数据。
2. 从顶栏「新建配置」选择模板。「手柄与体感」使用虚拟手柄，按住左扳机就能用体感控制右摇杆。
3. 在「游戏配置」页头选择键鼠、Xbox 360 或 DualShock 4 输出。「动作映射 → 添加动作」可选或录入手柄输入，再选择触发方式和键鼠输出。体感动作与定角转身也从动作列表编辑。在「摇杆」调死区和 Flick Stick，在「扳机」调轻拉、全拉和行程，在「触控」调触摸板手势，在「体感」调灵敏度、方向和防抖。姿态／摇杆旋转模式需要虚拟手柄；玩家／世界坐标及倾斜动作需要加速度计。
4. 点击顶栏的「启动映射」开始输出。「停止映射」或 F12 会释放输出。关闭应用会停止输出，最小化时可继续运行。
5. 要在菜单使用手柄布局，可创建“虚拟手柄”配置，然后设置光标显示时切过去、隐藏时恢复。没有系统光标变化的游戏可在「自动切换 → 快捷键切换」选择目标配置，默认按 F9 切换，再按一次返回；点击「录入快捷键」可改用单键或 Ctrl／Alt／Shift 组合，Esc 取消，修改自动保存。F12 保留为紧急停止键。

默认键鼠后端为 HIDMaestro；虚拟 Xbox／DS4 默认使用 FlexInput 原生 ViGEm，需要 ViGEmBus，也可单独改选 HIDMaestro 手柄。HidHide 用于解决实体和映射输出同时被游戏读取的问题。安装组件后，开始映射默认自动隐藏所选实体手柄，保留虚拟输出可见；断线等待保留会话，停止、F12 或退出恢复本次新增规则。仅观察和手柄操作界面不会新增隐藏。可以在「设置与组件」关闭自动隐藏并自行管理规则。详见[隐藏生命周期](docs/hidhide-lifecycle.md)和[游戏转角校准](docs/game-angle-calibration.md)。

在「游戏配置」或「配置库」选择「导入 JSM 配置」，先查看报告再创建。顶栏「手柄操作」暂停映射并进入界面导航，Menu 可继续游戏，前台 View + Menu 可切回界面。详见 [JSM 导入](docs/jsm-import.md)和[手柄操作](docs/gamepad-ui.md)。

按住 LB 使用不同灵敏度：在基础层把 LB 映射到鼠标右键，添加以 LB 启用的配置层，在该层编辑体感灵敏度。更多操作见[配置层、触发方式与运行中录入](docs/action-layers-and-triggers.md)，示例见 [hold-layer.toml](examples/hold-layer.toml)。在左下角选择界面语言，旁边按钮切换主题；在「自动切换」设置并预览[配置切换提示](docs/configuration-overlay.md)。

顶栏当前配置右侧的「编辑层」在各页面共用，齿轮按钮打开「管理配置层」。选择编辑层只决定修改写入哪一层，实际运行仍由按住输入决定。光标切换延迟在「自动切换 → 光标显示状态 → 状态确认时间」设置，输入后回车或移开焦点保存。设为 0 取消额外确认等待；约 50 ms 检查周期和配置加载仍会影响响应，详见[光标自动切换](docs/cursor-switching.md)。

## 配置与数据

一份 TOML 包含配置名、动作、体感、摇杆、配置层和虚拟手柄设置，可以直接导出分享。设备路径、HidHide 规则、静止零偏、全局切换规则、界面语言和浮层偏好属于本机，不混入分享文件。0.8.0 配置层和触发方式需要对应版本读取；旧配置缺失新字段时使用原行为的默认值。

默认数据位置为当前用户的 AppData/Roaming/io.hotuns.motionstudio，可在「设置与组件」打开。测试可用 MOTION_STUDIO_DATA_DIR 指定隔离目录。保存采用临时文件、刷新、原子替换，并保留上一份有效文件的 .bak。配置 ID 不随名字改变。

示例见 examples/。格式版本为 `schema_version = 1`。旧配置中的 `virtual_gamepad = true` 对应 `"xbox_360"`，`false` 对应 `"none"`。保存或导出时写入目标名称，DualShock 4 使用 `"dualshock_4"`。新版本自动补齐新增设置的默认值，旧单键动作可直接读取；组合键、滚轮、侧键及连续滚动配置需要 0.4.0 或后续版本。未知字段和版本会被明确拒绝。动作说明见 [docs/bindings.md](docs/bindings.md)，完整体感说明见 [docs/motion.md](docs/motion.md)。

## 当前边界

- 支持 Windows x64。玩家／世界坐标、倾斜与去重力加速度已接入；轴向、长期握持与游戏手感需要用户在真实设备上验收。当前使用单个设备的 IMU，不包含多传感器融合。
- DualShock 4 输出提供标准输入报告，实体手柄有触摸板按键时也可映射点按。DualSense（PS5）是另一种设备，FlexInput 使用单独的 HIDMaestro 后端。当前的 ViGEmBus 输出范围为 Xbox 360 和 DualShock 4。 [ViGEmBus 支持的设备](https://github.com/nefarius/ViGEmBus#emulated-devices)
- 光标切换读取 Windows 系统光标可见性，不能识别游戏自己绘制的光标或判断是否进入战斗。
- 自动重连要求原设备路径一致。换 USB 口、接收器或连接模式后需要重新选择接口。只报告 XInput 槽位的设备断开后也需要重新选择。
- 引擎崩溃后恢复待机，不自动重新发送按键。连续一分钟内三次故障后停止自动重试。
- JSM 关联文件在预览时展开。复杂手柄重排和动态载入规则需查看转换报告并手动调整。
- 不保证跨权限等级输入或任意游戏/反作弊兼容性；软件不修改游戏进程。

0.6.0 默认使用 FlexInput 的 HIDMaestro 原生 HID 输出，覆盖键盘、组合键、相对鼠标、双向滚轮、侧键及 Xbox／DS4。兼容模式保留 SendInput／ViGEm；观察和手柄操作界面不创建输出设备。首次安装及设备创建需要用户在 Windows 中授权。详见 [HIDMaestro 使用说明](docs/hidmaestro-output.md) 和 [游戏兼容性边界](docs/output-compatibility.md)。

SDL3 3.4.18 使用已对照验证的 Flydigi device 150 陀螺仪轴向补丁，仅修正陀螺仪轴，不修改加速度。源码补丁和来源在 vendor/sdl-patches/。引擎内不重复做厂商轴向修正。

依赖来源、移植改动和架构详见 docs/architecture.md、THIRD_PARTY_NOTICES.md 和 vendor/flexinput/manifest.json。
