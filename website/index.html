02 / 从这里开始

连接。配置。开始游戏。

01

连接你的手柄

安装并打开 Motion Studio，在工作台检查设备与输入。使用体感功能需要手柄支持陀螺仪。

02

选择输出与配置

根据游戏选择键鼠或虚拟手柄输出，再设置动作映射；需要的输出组件可在软件内查看和安装。

03

校准，再调手感

用游戏内转角校准核对实际转身角度，再微调灵敏度、Flick 曲线和防抖。

使用虚拟摇杆 Flick？

先把游戏摇杆响应曲线设为线性，关闭边缘和其他转向加速。完成校准后，保持游戏内灵敏度不变。

你可能想知道

所有手柄都能使用体感吗？＋

体感瞄准需要设备具备陀螺仪，并能被输入后端读取。没有陀螺仪的手柄也可以使用按键映射、摇杆设置，以及独立启用的 Flick 和配套摇杆瞄准。

鼠标输出和虚拟摇杆输出怎么选？＋

根据游戏接受的输入类型选择。鼠标输出需要校准鼠标计数与游戏转角的换算；虚拟右摇杆输出需要校准游戏的实际满杆角速度，转身速度也会受游戏本身的限制。

更新后需要重新配置吗？＋

安装版更新沿用原来的配置和本机设置。可以在「设置与组件 → 软件更新」检查更新，也可以从 GitHub 下载新版安装包。

遇到问题，或者想分享配置？＋

欢迎到 GitHub Issues 反馈问题。请附上软件版本、手柄型号、输出方式和复现步骤；分享配置前可以先导出配置文件。
